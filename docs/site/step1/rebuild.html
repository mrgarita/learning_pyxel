番外 公開版を作り直す

Candy Hunt の 2 本を、ESC でゲームが止まらないようにする

トップページ ／ step1 概要 ／ 公開版を作り直す

ゴール

公開している Candy Hunt の 2 本（PC 版・スマホ版）は、 遊んでいる途中で ESC を押すと、ゲームが止まります。 step2 の公開のときに見つけた問題です（step2 フェーズ 12 の 1-3）。 倉庫番と同じように直して、公開しなおします。

ブラウザで 1 秒待ったあいだに、pyxel.frame_count がいくつ進んだかを測りました。

　ESC を押す直前押して 1 秒後そのあと → を押す
いまの公開版103104（止まった）男の子は動かない
作り直した版104144（動いている）右へ動く

直すコードは 2 本とも 1 行ずつです。手間がかかるのは公開版の HTML の作り直しのほうですが、 全画面ボタンを足し直さずにすむ方法があるので、それを使います（1-2）。

1. 考え方

1-1. 直すのは pyxel.init() の 1 行

倉庫番と同じく、pyxel.init() に quit_key=pyxel.KEY_NONE を足します。 「ESC で終わる」をやめる指定です。しくみとキーワード引数の説明は step2 フェーズ 12 の 1-3 にあります。 

pyxel.init(SCREEN_WIDTH, SCREEN_HEIGHT, title="Candy Hunt", quit_key=pyxel.KEY_NONE)

1-2. 公開版の HTML で、ゲーム本体は 1 行だけ

pyxel app2html が作る HTML は 5 行しかなく、ゲーム本体（.pyxapp を文字にしたもの）は launchPyxel( で始まる 1 行に全部入っています。 PC 版の candy_hunt.html は、その 5 行に文字コードの 1 行と全画面ボタンを手で足したものです。

つまり、ゲームを直して公開しなおすときは、launchPyxel( の 1 行だけを入れかえれば、 手で足した部分はそのまま残ります。

スマホ版の candy_hunt_mobile.html は、手で何も足していません（app2html が作ったそのまま）。 こちらは、作り直した HTML でそのまま上書きすれば済みます。

行の場所は「何行目か」より「何で始まるか」で探す 作り直した直後の HTML では 4 行目、candy_hunt.html では文字コードの 1 行が増えているので 5 行目です。 どちらも launchPyxel( で始まる行は 1 つしかないので、それを目印にします。

1-3. どちらのパッケージにも、スクリプトが 2 本入る

step1/ には candy_hunt.py と candy_hunt_mobile.py が並んでいます。 pyxel package はフォルダの中身をまるごと詰めて、起動するスクリプトを 1 つ記録するだけなので、 どちらを作っても 2 本とも入ります（備忘録）。

どちらも GitHub で公開しているコードなので、入っていてかまいません。スマホ版はいまもこの形です。 いまの PC 版はスマホ版を作る前に作ったので、作り直すと中身が 1 本増えて、HTML が 3 KB ほど大きくなります（7 KB → 11 KB ほど）。

2. 手順

PC 版 → スマホ版の順に、1 本ずつ作ります。 pyxel package step1 … は、どちらを作っても step1.pyxapp と step1.html という同じ名前になり、 2 本目が 1 本目を上書きするからです。

2-1. コードを直す（2 ファイル）

step1/candy_hunt.py の __init__()：

class App:
    def __init__(self):
        """起動時の設定"""
        pyxel.init(SCREEN_WIDTH, SCREEN_HEIGHT, title="Candy Hunt", quit_key=pyxel.KEY_NONE)   ← 書きかえ
        pyxel.load("candy_hunt.pyxres")

step1/candy_hunt_mobile.py も同じ場所です（title だけちがう）。

class App:
    def __init__(self):
        """起動時の設定"""
        pyxel.init(SCREEN_WIDTH, SCREEN_HEIGHT, title="Candy Hunt Mobile", quit_key=pyxel.KEY_NONE)   ← 書きかえ
        pyxel.load("candy_hunt.pyxres")

それぞれ実行して、ESC を押してもウィンドウが閉じないこと、右上の × で閉じられることを確かめます。

最後に、step1/ に tempCodeRunnerFile.py があれば消します （step2 フェーズ 12 の 3-2 と同じ）。

2-2. PC 版を作る

リポジトリのいちばん上で実行します。

pyxel package step1 step1/candy_hunt.py

一覧がこの 4 行なら OK です（1-3）。

added 'step1\.pyxapp_startup_script'
added 'step1\candy_hunt.py'
added 'step1\candy_hunt.pyxres'
added 'step1\candy_hunt_mobile.py'

手元で動かして、ESC で閉じないことを確かめてから（閉じるのは ×）、HTML にします。

pyxel play step1.pyxapp
pyxel app2html step1.pyxapp

リポジトリの直下に step1.html ができます。

2-3. PC 版：launchPyxel( の 1 行を入れかえる

  1. VS Code で直下の step1.html を開き、launchPyxel( で始まる行（4 行目）のどこかをクリックする
  2. Ctrl＋L を 1 回押す（行全体が選ばれる）→ Ctrl＋C
  3. docs/site/step1/candy_hunt.html を開き、launchPyxel( で始まる行（5 行目）のどこかをクリックする
  4. Ctrl＋L を 1 回 → Ctrl＋V → 保存

保存したら、launchPyxel( で始まる行が1 つだけで、いちばん下の </script> が45 行目のまま（入れかえる前と同じ）であることを確かめます。

Ctrl＋L は「いまの行をまるごと選ぶ」 行末の改行までまとめて選ぶので、コピーして貼ると、行がそっくり置きかわります。 とても長い 1 行（1 万文字ほど）でも、右端まで引っぱって選ぶ必要がありません。 2 回押すと次の行まで選ばれる（</script> を消してしまう）ので、1 回だけにします。

2-4. スマホ版を作る

pyxel package step1 step1/candy_hunt_mobile.py
pyxel play step1.pyxapp
pyxel app2html step1.pyxapp

一覧は 2-2 と同じ 4 行です（起動するスクリプトがちがうだけ）。 step1.pyxapp と step1.html は、PC 版のものが上書きされます。

できた step1.html を docs/site/step1/candy_hunt_mobile.html へ移動して、上書きします （手で足した部分がないので、入れかえではなく上書きで済みます。1-2）。 これで直下の step1.html はなくなります。

2-5. 手元のブラウザで確かめる

リポジトリのいちばん上で python -m http.server を起動し、Chrome で 2 つの URL を開きます。

http://localhost:8000/docs/site/step1/candy_hunt.html
http://localhost:8000/docs/site/step1/candy_hunt_mobile.html
　することこうなれば OK
1PC 版を開くCLICK TO START と、右下に「全画面」（文字が化けていない）
2クリック → Enter → 遊んでいる途中で ESC何も起きない。そのまま矢印キーで動ける
3「全画面」をクリック → ESC広がって、元に戻る。まだ動ける
4スマホ版を開く → クリック → Enter → 遊んでいる途中で ESC何も起きない。そのまま矢印キーで動ける
古い版が出てくるときは ブラウザが前の版を覚えていることがあります。CLICK TO START の画面のうちに Ctrl＋F5 で読み込みなおします（ゲームが始まったあとは F キーが効きません。 備忘録）。

2-6. コミットして、公開 URL を開く

コミットするのは次の 4 つです。

step1/candy_hunt.py
step1/candy_hunt_mobile.py
docs/site/step1/candy_hunt.html
docs/site/step1/candy_hunt_mobile.html

push して 1〜2 分待ったら、PC で PC 版 を、 スマホで スマホ版 を開いて遊べることを確かめます。

3. うまくいかないときは

2-3 の入れかえで起きやすいものを、実際にその形の HTML を作って確かめました。

症状原因
真っ白で CLICK TO START が出ない。右下の「全画面」だけ出る 貼った 1 行が途中で切れている（コピーするとき右端まで選べていなかった）
真っ白で、何も出ない（「全画面」も出ない） Ctrl＋L を 2 回押して、次の </script> の行まで上書きした
CLICK TO START が大小 2 つ重なって出る 選ばずに貼ったので、launchPyxel( の行が古いのと新しいので 2 つある
遊べるが、「全画面」ボタンがない PC 版を、入れかえではなく上書きした

どれも、candy_hunt.html を元に戻してから、2-3 をやり直すのがいちばん早いです。 VS Code のソース管理で candy_hunt.html を右クリック →「変更を破棄」で、最後にコミットした形に戻ります （直下の step1.html は PC 版のものが必要なので、2-4 より前なら残っています。2-4 のあとなら 2-2 からやり直します）。
