フェーズ 10 効果音と BGM

音を 7 つ作り、鳴らしたい瞬間の隣に 1 行ずつ足す

トップページ ／ step2 概要 ／ フェーズ 10

ゴール

歩いた・押した・ゴールに乗せた・クリアしたの 4 つに効果音をつけ、遊んでいるあいだは BGM を流します。 できあがると、こう聞こえます（▶ で再生。音が出ます）。

step1 フェーズ 9 の復習です step1 フェーズ 9 で覚えたこと——チャンネルを分ける、 play と playm、stop() を先に書く——はそのまま使います。
新しいのは 2 つだけです。① ジングルの長さを、フェーズ 9 で作った「間」（CLEAR_WAIT）にぴったり合わせる。 ② BGM を鳴らしはじめる場所を start_game() の 1 か所に集める。
コードで足すのは 19 行、書き換えは 3 行（と先頭のフェーズ名）。時間がかかるのは、リソースエディタで音を作るほうです。

1. 考え方

1-1. 鳴らす場所は、もうできている

フェーズ 9 の 8 章で予告したとおり、音を鳴らすタイミングはすでにコードの中にあります。 歩数を増やしている行、荷物を押している行、クリアした時刻を覚えている行——そのすぐ隣に 1 行足すだけです。

効果音は、変化させている行の隣で鳴らす step1 で決めた約束です。self.steps += 1（歩数が増えた）の隣で歩いた音、 self.pushing = True（押した）の隣で押した音、 self.clear_frame = …（クリアした）の隣でジングル。 「そのできごとが本当に起きた」と決まった行の隣なので、音とできごとが必ずそろいます。

1-2. チャンネルの割り当て：歩いた音だけ別にする

チャンネルは 4 本。BGM が ch0・ch1 を使うので、効果音は ch2・ch3 にまわします（step1 と同じ）。

気をつけたいのは、リンゴを押した 1 歩です。このときは歩いた音と押した音が、同じフレームで鳴ります。 同じチャンネルで鳴らすと、あとから鳴らしたほうが前の音を止めてしまいます （備忘録「5 個目だけ音が化ける」と同じしくみ）。 実際に 2 つを同じチャンネルにして 2 面を解いてみると、押した音・乗せた音は 6 回とも 1 度も聞こえませんでした（6-1）。

押した音・乗せた音・ジングルは、同じ ch3 でかまわない理由 押した音と乗せた音は、どちらか 1 つしか鳴らしません（押した先がゴールなら乗せた音、ちがえば押した音。6-3）。 ジングルが鳴るのは、最後の 1 歩が着いたとき——押しはじめてから 8 フレーム後です。 そのころには、乗せた音（4 フレーム）はもう鳴り終わっています。 同時に鳴ることがない音どうしなら、同じチャンネルを使い回せます。

1-3. ジングルの長さを、フェーズ 9 の「間」にぴったり合わせる

フェーズ 9 で、クリアしてから CLEAR! が出るまでに 20 フレーム（0.67 秒）の間を作りました。この間に、ちょうど収まる長さのジングルを鳴らします。

長さの計算は step1 で測った 1 音の秒数 ＝ SPEED ÷ 120 です。 Pyxel は 1 秒が 30 フレームなので、フレームで数えると ＝ SPEED ÷ 4 になります。

SPEED1 音のフレーム数このフェーズで使う音

ジングルは 8 音 × 10 ÷ 4 ＝ 20 フレーム。CLEAR_WAIT と同じです。 こうしておくと、ジングルが鳴り終わる・輪が消える・CLEAR! が出る・Enter が効くようになる—— この 4 つが同じフレームでそろいます。

1-4. BGM は start_game() で鳴らしはじめる

BGM を鳴らしはじめるのはステージが始まるときです。いまのコードで、ステージが始まる入口は 3 つあります。

入口いま呼んでいるもの
ステージ選択で Enterstart_game()
クリアのあと Enter で次の面（next_stage()）load_stage()
R でやり直すload_stage()

3 つの入口それぞれに playm を書くこともできますが、3 つとも start_game() を通るように変えて、 playm は start_game() に 1 行だけ書きます。 step1 で start_game() を作ったのと同じ考え方です（step1 フェーズ 9 の 3-6）。

R を load_stage() のままにすると、クリアのあとのやり直しが無音になります クリアした瞬間に stop() で BGM を止めるからです。CLEAR! が出ている画面で R を押すと、 盤面は最初に戻るのに BGM は止まったまま。実際に試すと、そうなりました（6-4）。

そのかわり、遊んでいる途中で R を押しても BGM は頭から鳴りなおします。 「やり直す」が音でも分かる、と考えてこちらにしました。 途中では鳴りつづけてほしい、と感じたらもう一歩に直し方があります。

打ち方のおさらい 音符は1 音ごとに「キー → Enter」。TONE・VOL・EFFECT は ↓ でその行に移って打ちます。 TONE や VOL を 1 つだけ入れると、すべての音に使われます（足りない分は先頭からくり返す）。 だから N や 3 は 1 つ打てば足ります。SOUND 3 の EFFECT だけは 8 つ打ちます。
OCTAVE を行き来しないで済む順：OCTAVE 3 のまま SOUND 0 → 2 → 3 → 4 → 5（3-3 のメロディまで） → PageDown を 2 回押して OCTAVE 1 にし、SOUND 1 → 6。
SOUND 3 の最後の G4 G4 G4 は、つながって 1 つの長い音になる EFFECT が N のまま同じ高さが続くと、切れ目なくつながります （step1 でベースが「棒読み」に聞こえたのと同じしくみを、今回はわざと使っています）。 最後の 1 つだけ F（フェードアウト）にしておくと、のばした音がすっと消えて、そこで CLEAR! が出ます。
どの音も、なぜこの形にしたか
  • 歩いた音はノイズ（N）：音の高さがないので、BGM のメロディとぶつかりません。押しっぱなしで歩くと 1 秒に 4 回近く鳴るので、 音量も 3 と小さめです。
  • 押した音は 1 歩（8 フレーム）より短い 6 フレーム：続けて押しても、前の音が切られずに鳴り終わります。 下がる 2 音で「ゴトッ」と重さを出しています。
  • 乗せた音は上がる 2 音：上がる音＝よいこと（step1）。
  • クリアは 20 フレーム：1-3 のとおり、CLEAR_WAIT にぴったり。
これは長さと音量のつり合いを測って決めた「たたき台」です。聞いてみて直したくなったら、そちらが正解です（もう一歩に直し方のヒント）。

step1 はベースが 2 周してメロディに合わせましたが、今回は和音が 1 小節ごとに変わり、4 小節で 1 周する （ド・ミ・ソ → ラ・ド・ミ → ファ・ラ・ド → ソ・シ・レ）ので、ベースも 4 小節ぶんを 1 周にしました。

3-6. BGM は start_game() で鳴らし、入口を 3 つともそこへ通す

まず start_game() に playm を 1 行足します（説明の 1 行も、中身に合わせて書き換え）。 

    def start_game(self):
        """いまの stage_no のステージを読み込んで、BGM を鳴らしはじめる"""   ← 書き換え（説明だけ）
        self.load_stage(STAGES[self.stage_no])
        self.scene = SCENE_GAME
        pyxel.playm(MUSIC_BGM, loop=True)                                ← 足す

次に、update_game() の R を start_game() に書き換えます。 

        if pyxel.btnp(pyxel.KEY_R):             # いつでも、最初からやり直せる
            self.start_game()                   # BGM も頭から鳴らしなおす   ← 書き換え
            return

最後に、next_stage() も start_game() に書き換えます。 

    def next_stage(self):
        """次のステージへ進む。最後だったら全クリア"""
        if self.stage_no + 1 < len(STAGES):
            self.stage_no += 1
            self.start_game()                   # 読み込みと BGM は start_game() にまかせる   ← 書き換え
        else:
            self.all_cleared = True
start_game() を呼んでも、ほかに困ることはない？ start_game() の中身は、load_stage() と self.scene = SCENE_GAME と playm の 3 行です。 R や次の面へ進むときは、もともと SCENE_GAME なので、scene の行は何も変えません。 増えるのは playm だけ——ちょうど足したかったものです。

3-7. Q で選択画面へ戻るときは止める

        if pyxel.btnp(pyxel.KEY_Q):             # ステージ選択へもどる
            pyxel.stop()                        # 選択画面では BGM を止める   ← 足す
            self.scene = SCENE_SELECT

try_move() の後半です。押した音と乗せた音は荷物の if の中、歩いた音はいちばん最後に足します。

def draw_center(text, y, color):

def draw_right(text, y, color):

def is_blink_on():
    """点滅の「見えている」タイミングなら True を返す"""
    return pyxel.frame_count % BLINK_CYCLE < BLINK_ON

class App:
    def __init__(self):
        """起動時の設定"""
        pyxel.init(SCREEN_WIDTH, SCREEN_HEIGHT, title="Sokoban")
        pyxel.load("sokoban.pyxres")
        self.scene = SCENE_TITLE        # 起動したら、まずタイトル画面
        self.stage_no = 0               # いま何番目のステージか（0 から数える）
        self.cleared_count = 0          # クリアした面の数（終了すると消える）
        self.all_cleared = False        # 10 個ぜんぶ終わったか
        pyxel.run(self.update, self.draw)

    def opened_count(self):
        """選べる面の数。クリアした数より 1 つ先まで開く"""
        return min(self.cleared_count + 1, len(STAGES))

    def start_game(self):
        """いまの stage_no のステージを読み込んで、BGM を鳴らしはじめる"""
        self.load_stage(STAGES[self.stage_no])
        self.scene = SCENE_GAME
        pyxel.playm(MUSIC_BGM, loop=True)

    def load_stage(self, rows):
        """文字の地図を読んで、壁・主人公・荷物に分ける"""
        self.tiles = []
        self.boxes = []
        self.player_dir = DIR_DOWN      # はじめは下を向いている
        self.walk_timer = 0             # 0 なら止まっている。1～8は歩いている途中
        self.pushing = False            # いまの一歩で荷物を押しているか
        self.cleared = False            # このステージをクリアしたか
        self.steps = 0                  # このステージで歩いた数

        for y in range(len(rows)):
            line = []
            for x in range(len(rows[y])):
                mark = rows[y][x]
                if mark == "@":
                    self.player_x = x
                    self.player_y = y
                    mark = "."          # 主人公の足元は床
                elif mark == "$":
                    self.boxes.append([x, y])
                    mark = "."          # 荷物の下も床
                line.append(mark)
            self.tiles.append(line)

        self.from_x = self.player_x     # 見た目の出発マス
        self.from_y = self.player_y

        # 盤面を画面の中央に置くための、ずらし幅
        board_w = len(self.tiles[0]) * TILE
        board_h = len(self.tiles) * TILE
        self.ox = (SCREEN_WIDTH - board_w) // 2
        self.oy = HUD_HEIGHT + (SCREEN_HEIGHT - HUD_HEIGHT - board_h) // 2

    def update(self):
        """フレーム毎の更新処理。いまの画面の担当へ渡す"""
        if self.scene == SCENE_TITLE:
            self.update_title()
        elif self.scene == SCENE_SELECT:
            self.update_select()
        else:
            self.update_game()

    def update_title(self):
        """タイトル画面。Enter でステージ選択へ"""
        if pyxel.btnp(pyxel.KEY_RETURN):
            self.scene = SCENE_SELECT

    def update_select(self):
        """ステージ選択。矢印でカーソルを動かし、Enter で始める"""
        if pyxel.btnp(pyxel.KEY_LEFT):
            self.move_cursor(-1)
        elif pyxel.btnp(pyxel.KEY_RIGHT):
            self.move_cursor(1)
        elif pyxel.btnp(pyxel.KEY_UP):
            self.move_cursor(-SELECT_COLS)      # 1 段上は、5 つ前
        elif pyxel.btnp(pyxel.KEY_DOWN):
            self.move_cursor(SELECT_COLS)       # 1 段下は、5 つ後

        if pyxel.btnp(pyxel.KEY_RETURN):
            self.start_game()

    def move_cursor(self, step):
        """カーソル（stage_no）を step だけ動かす。選べない面へは動かない"""
        next_no = self.stage_no + step
        if 0 <= next_no < self.opened_count():
            self.stage_no = next_no

    def update_game(self):
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE
            return

        if pyxel.btnp(pyxel.KEY_Q):             # ステージ選択へもどる
            pyxel.stop()                        # 選択画面では BGM を止める
            self.scene = SCENE_SELECT
            return

        if pyxel.btnp(pyxel.KEY_R):             # いつでも、最初からやり直せる
            self.start_game()                   # BGM も頭から鳴らしなおす
            return

        if self.cleared:                        # クリアした。間をおいてから、Enter で次のステージへ
            if self.clear_elapsed() >= CLEAR_WAIT and pyxel.btnp(pyxel.KEY_RETURN):
                self.next_stage()
            return
        
        if self.walk_timer > 0:                 # 歩いている途中
            self.walk_timer += 1
            if self.walk_timer > MOVE_FRAMES:   # 隣のマスに着いた
                self.walk_timer = 0
                self.from_x = self.player_x     # 見た目を、いまいるマスに合わせる
                self.from_y = self.player_y
                self.pushing = False
                if self.is_cleared():           # 着いた、その瞬間に調べる
                    self.cleared = True
                    self.clear_frame = pyxel.frame_count    # クリアした時刻を覚えておく
                    pyxel.stop()                            # BGM を止めてから
                    pyxel.play(CH_SE, SOUND_CLEAR)          # クリアのジングル
                    # 何面目までクリアしたかを覚える。前の記録より小さくはしない
                    self.cleared_count = max(self.cleared_count, self.stage_no + 1)

        # 止まっていて、まだクリアしていないときだけ、キーを見る    
        if self.walk_timer == 0 and not self.cleared:
            self.handle_key()

    def handle_key(self):
        """矢印キーを見て、押された向きへ 1 歩進もうとする"""
        if pyxel.btn(pyxel.KEY_DOWN):
            self.try_move(DIR_DOWN)
        elif pyxel.btn(pyxel.KEY_UP):
            self.try_move(DIR_UP)
        elif pyxel.btn(pyxel.KEY_LEFT):
            self.try_move(DIR_LEFT)
        elif pyxel.btn(pyxel.KEY_RIGHT):
            self.try_move(DIR_RIGHT)

    def has_box(self, x, y):
        """そのマスに荷物があるかどうかを答える"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                return True
        return False

    def move_box(self, x, y, dx, dy):
        """(x, y) にある荷物を、(dx, dy) だけ動かす"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                box[0] += dx
                box[1] += dy
                return

    def on_goal(self, box):
        """その荷物が、ゴールのマスに乗っているか"""
        return self.tiles[box[1]][box[0]] == "O"

    def is_cleared(self):
        """すべての荷物がゴールに乗ったか"""
        return all(self.on_goal(box) for box in self.boxes)

    def clear_elapsed(self):
        """クリアしてから何フレームたったか"""
        return pyxel.frame_count - self.clear_frame

    def next_stage(self):
        """次のステージへ進む。最後だったら全クリア"""
        if self.stage_no + 1 < len(STAGES):
            self.stage_no += 1
            self.start_game()                   # 読み込みと BGM は start_game() にまかせる
        else:
            self.all_cleared = True

    def try_move(self, direction):
        """その向きへ動けるか調べて、動けるときだけ 1 マス進む"""
        self.player_dir = direction     # 動けなくても、向きだけは変える

        dx, dy = MOVES[direction]
        next_x = self.player_x + dx
        next_y = self.player_y + dy

        if self.tiles[next_y][next_x] == "#":   # 行き先が壁なら
            return                              # 何もしないで戻る

        if self.has_box(next_x, next_y):        # 行き先に荷物があるなら
            far_x = next_x + dx                 # 荷物の、1 つ先のマス
            far_y = next_y + dy
            if self.tiles[far_y][far_x] == "#": # その先が壁なら押せない
                return
            if self.has_box(far_x, far_y):      # その先に別の荷物があっても押せない
                return
            self.move_box(next_x, next_y, dx, dy)
            self.pushing = True                 # この一歩は、荷物を押している
            if self.tiles[far_y][far_x] == "O": # 押した先がゴールなら
                pyxel.play(CH_SE, SOUND_GOAL)   # 乗せた音
            else:
                pyxel.play(CH_SE, SOUND_PUSH)   # 押した音

        self.player_x = next_x
        self.player_y = next_y
        self.walk_timer = 1                     # ここから 8 フレームかけて歩く
        self.steps += 1                         # 動けたときだけ、1 歩と数える
        pyxel.play(CH_STEP, SOUND_STEP)         # 歩いた音（押したときも鳴る）

    def slide_pos(self, origin, from_cell, to_cell):
        """出発マスから到着マスへ、いまどこまで来たかをドットで返す"""
        moved = (to_cell - from_cell) * TILE * self.walk_timer // MOVE_FRAMES
        return origin + from_cell * TILE + moved

    def draw(self):
        """フレーム毎の描画処理。画面を消してから、担当へ渡す"""
        pyxel.cls(pyxel.COLOR_BLACK)    # 各画面で使うので、ここに 1 回だけ

        if self.scene == SCENE_TITLE:
            self.draw_title()
        elif self.scene == SCENE_SELECT:
            self.draw_select()
        else:
            self.draw_game()

    def draw_title(self):
        """タイトル画面を描く"""
        draw_center("SOKOBAN", 30, pyxel.COLOR_YELLOW)
        draw_center("PUSH THE APPLES", 44, pyxel.COLOR_WHITE)

        # ワンコが、リンゴをゴールへ押していく絵
        x = SCREEN_WIDTH // 2 - TILE * 2
        pyxel.blt(x, 66, 0, DIR_RIGHT * TILE, V_PLAYER_A, TILE, TILE, pyxel.COLOR_GRAY)
        pyxel.blt(x + TILE, 66, 0, U_BOX, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)
        pyxel.blt(x + TILE * 3, 66, 0, U_GOAL, V_TILE, TILE, TILE)

        if is_blink_on():               # 1 秒のうち 20 フレームだけ見える
            draw_center("PRESS ENTER", 92, pyxel.COLOR_WHITE)

        draw_center("ARROW: MOVE  R: RETRY  Q: SELECT", 108, pyxel.COLOR_GRAY)

    def draw_select(self):
        """ステージ選択の画面を描く"""
        draw_center("SELECT STAGE", 16, pyxel.COLOR_YELLOW)

        for no in range(len(STAGES)):
            col = no % SELECT_COLS              # 左から何番目か（0～4）
            row = no // SELECT_COLS             # 上から何段目か（0～1）
            x = 18 + col * 26
            y = 36 + row * 24

            if no < self.cleared_count:         # クリアした面
                color = pyxel.COLOR_LIME
            elif no == self.cleared_count:      # 次に挑む 1 面
                color = pyxel.COLOR_WHITE
            else:                               # まだ選べない面
                color = pyxel.COLOR_NAVY

            pyxel.rectb(x, y, 20, 16, color)
            label = f"{no + 1}"
            pyxel.text(x + (20 - len(label) * 4) // 2, y + 5, label, color)

            if no == self.stage_no:             # カーソルは、ひとまわり大きい枠
                pyxel.rectb(x - 2, y - 2, 24, 20, pyxel.COLOR_YELLOW)

        draw_center("ARROW: CHOOSE    ENTER: START", 96, pyxel.COLOR_GRAY)

    def draw_game(self):
        """あそんでいる画面を描く"""

        # 壁を、上の行から 1 マスずつ描く
        for y in range(len(self.tiles)):
            for x in range(len(self.tiles[y])):
                mark = self.tiles[y][x]
                if mark == "#":
                    u = U_WALL
                elif mark == "O":
                    u = U_GOAL
                else:
                    u = U_FLOOR
                pyxel.blt(self.ox + x * TILE, self.oy + y * TILE,
                            0, u, V_TILE, TILE, TILE)

        # クリアした直後は、リンゴから輪が広がる。リンゴの下から出てくるように、先に描く
        if self.cleared and self.clear_elapsed() < CLEAR_WAIT:
            r = self.clear_elapsed() // 2       # 2 フレームに 1 ドットずつ大きく
            for box in self.boxes:
                cx = self.ox + box[0] * TILE + TILE // 2
                cy = self.oy + box[1] * TILE + TILE // 2
                pyxel.circb(cx, cy, r, pyxel.COLOR_YELLOW)

        # 荷物。押している 1 つだけは、主人公といっしょにすべる
        dx, dy = MOVES[self.player_dir]
        push_x = self.player_x + dx             # 押した荷物は主人公の目の前にいる
        push_y = self.player_y + dy
        for box in self.boxes:
            if self.pushing and box[0] == push_x and box[1] == push_y:
                bx = self.slide_pos(self.ox, box[0] - dx, box[0])
                by = self.slide_pos(self.oy, box[1] - dy, box[1])
            else:
                bx = self.ox + box[0] * TILE
                by = self.oy + box[1] * TILE
            u = U_BOX
            if self.on_goal(box):       # ゴールに乗っているあいだは別の絵
                u = U_BOX_ON_GOAL
            pyxel.blt(bx, by, 0, u, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)

        # 主人公
        px = self.slide_pos(self.ox, self.from_x, self.player_x)
        py = self.slide_pos(self.oy, self.from_y, self.player_y)
        v = V_PLAYER_A
        if self.walk_timer >= MOVE_FRAMES // 2:     # 歩きの後半は、足を入れ替える
            v = V_PLAYER_B
        d = self.player_dir
        if self.cleared and self.clear_elapsed() >= CLEAR_WAIT:
            d = DIR_DOWN                        # こちらを向いて
            if self.clear_elapsed() % 16 < 8:
                py -= 2                         # ぴょんと跳ねる
        pyxel.blt(px, py, 0, d * TILE, v, TILE, TILE, pyxel.COLOR_GRAY)

        # 画面の上の表示
        if self.all_cleared:
            draw_center("ALL CLEAR!  ENTER=TITLE", 3, pyxel.COLOR_YELLOW)
        else:
            pyxel.text(2, 3, f"STAGE {self.stage_no + 1}/{len(STAGES)}",
                       pyxel.COLOR_GRAY)
            draw_right(f"STEPS {self.steps}", 3, pyxel.COLOR_GRAY)
            if self.cleared and self.clear_elapsed() >= CLEAR_WAIT:
                draw_center("CLEAR!  ENTER", 3, pyxel.COLOR_YELLOW)
App()

            self.stage_no = next_no
            pyxel.play(CH_SE, SOUND_CURSOR)     # カーソルが動いた音   ← 足す
    if の中に書くので、まだ遊べない面へ動こうとしたときは鳴りません。 「動けない」ことも、音がしないことで伝わります。選択画面は BGM がないので、どのチャンネルでもかまいません。

6. コードの解説

6-1. 同じフレームで 2 つ鳴らすなら、チャンネルを分ける

歩いた音を CH_SE（押した音と同じ ch3）で鳴らすとどうなるか、2 面を解いて数えました。

歩いた音のチャンネル鳴らした回数（押す・乗せる）実際に聞こえた回数
CH_STEP（ch2）（今回）4 回・2 回4 回・2 回
CH_SE（ch3）4 回・2 回0 回・0 回

try_move() では、押した音（荷物の if の中）のほうが先、歩いた音（いちばん最後）があとです。 同じチャンネルだと、同じフレームのうちにあとの歩いた音が、押した音を上書きします。 押した音は 1 フレームも鳴らないまま、毎回消されていました。

「同じ瞬間に鳴らしたい音は、別のチャンネルへ」——step1 の 「5 個目だけ音が化ける」とまったく同じ理由です。

6-2. 鳴らす行も「関門をぜんぶ通ったあと」

歩いた音を try_move() のいちばん上に書くと、こうなります。 

    def try_move(self, direction):
        """その向きへ動けるか調べて、動けるときだけ 1 マス進む"""
        self.player_dir = direction     # 動けなくても、向きだけは変える
        pyxel.play(CH_STEP, SOUND_STEP)         # ✕ ここだと、壁ではね返されても鳴る

1 面のはじめに壁へ向かって押しつづけると、1 秒に 30 回鳴りました。「ザーッ」と鳴りっぱなしです。 止まっているあいだ、handle_key() は毎フレーム try_move() を呼ぶからです。

これはフェーズ 9 の 6-1で、self.steps += 1 を上に書いたら壁押しで 1 秒に 30 増えたのと同じことです。 数える行も、鳴らす行も、「本当に動けた」と決まった場所——関門をぜんぶ通ったあと——に書きます。 だから歩いた音は self.steps += 1 のすぐ隣なのです。

6-3. 押した音と乗せた音は、どちらか 1 つ

押した先がゴールかどうかは、far_x・far_y（リンゴが押されていく先）で調べます。 すぐ上で「その先が壁か」を調べたのと同じマスです。

変数どのマス
next_x, next_yワンコが進む先（＝押す前にリンゴがあったマス）
far_x, far_yリンゴが押されていく先

ここを next_x・next_y と書きまちがえると、ゴールに乗せても「ゴトッ」になります。 しかも next のマスがゴールなのは「押す前のリンゴがゴールの上にいた」とき、 つまりゴールから押し出したときに「ピコッ」が鳴ります。ちょうど反対です。 10 面ぜんぶ解いて数えると、本当は 40 回鳴る「ピコッ」が、押し出した 7 回だけ鳴りました。

もう 1 つ。乗せた音は押しはじめた瞬間に鳴ります。リンゴがゴールに着くのは 8 フレーム後なので、 「早すぎない？」と思うかもしれません。ところが、リンゴの絵が変わるのも押しはじめた瞬間なのです。

フェーズ 5 から、on_goal(box) は盤面上の位置で調べています。 フェーズ 4 で決めたとおり、盤面上の位置は押した瞬間にもう先のマスです。 絵が変わる瞬間と音が鳴る瞬間がそろっているので、ずれては感じません。

6-4. 入口を 1 つにすると、書き忘れが起きない

R と next_stage() を load_stage() のままにしておくと、どうなるか試しました。

書き換え忘れ起きること
R が load_stage() のままCLEAR! の画面で R → 盤面は戻るが無音
next_stage() が load_stage() のままEnter で 2 面へ → 2 面からずっと無音

どちらもエラーは出ません。音が鳴らないだけなので、気づきにくいまちがいです。 入口ごとに playm を書く方法だと、入口が増えるたびに「書き忘れていないか」を気にすることになります。 入口を start_game() の 1 つにまとめておけば、playm の書き忘れは起きようがありません。

フェーズ 7 で作った start_game() が、ここで役に立つ フェーズ 7 で、start_game() を「いまの stage_no から始める係」として作りました。 フェーズ 8 では選択画面から、そして今回は R と次の面から呼んでいます。 「始める」がいつも同じ関数を通るので、始めるときにやりたいこと（BGM）を 1 か所に足すだけで、全部の入口に効きます。

6-5. stop() は play() の前（step1 の復習）

3-8 の 2 行を逆にすると、ジングルを鳴らした直後に stop() がch3 のジングルごと止めてしまい、クリアしても何も聞こえません （実際に試すと、クリアした瞬間に 4 本とも止まっていました）。 stop() は「ここまでの音を全部消す」、play() は「ここから鳴らす」。 消してから鳴らす、の順です。

7. うまくいかないときは

症状原因と対処
どの音も鳴らない リソースエディタで Ctrl＋S を押していないか、保存のあとゲームを起動しなおしていない（3-4）
押しても「ゴトッ」も「ピコッ」も聞こえない（「サッ」だけ） 歩いた音を CH_SE で鳴らしています。CH_STEP にします（6-1）。 CH_STEP と CH_SE が同じ数になっていないかも確かめてください
壁に向かって押しつづけると「ザーッ」と鳴りっぱなし 歩いた音を try_move() の上のほうに書いています。いちばん最後、self.steps += 1 の下へ（6-2）
ゴールに乗せても「ゴトッ」。ゴールから押し出すと「ピコッ」（反対になる） self.tiles[next_y][next_x] で調べています。far_y・far_x にします（6-3）
床へ 1 歩動いた瞬間に UnboundLocalError: cannot access local variable 'far_y' where it is not associated with a value 押した音・乗せた音の if の字下げが浅く、荷物の if の外に出ています。スペース 12 個に（3-9）
クリアしてもジングルが鳴らない（BGM は止まる） pyxel.stop() が pyxel.play(CH_SE, SOUND_CLEAR) のあとにあります。前へ（6-5）
ジングルの途中で CLEAR! が出る SOUND 3 の SPEED が 10 になっていません。はじめの 30 のままだと 8 音で 60 フレーム（2 秒）です（1-3）
CLEAR! の画面で R を押すと、BGM が鳴らない R が self.load_stage(STAGES[self.stage_no]) のままです。self.start_game() に（3-6）
2 面から BGM が鳴らない next_stage() が load_stage() のままです。self.start_game() に（3-6）
選択画面に戻っても BGM が鳴りつづける Q のところに pyxel.stop() がありません（3-7）
BGM が 6.4 秒で止まる playm に loop=True がありません
効果音が鳴るたびに、BGM のどこかが途切れる MUSIC 0 の ch2 か ch3 に SOUND を入れています。空にします（3-4）
選択画面で Enter を押した瞬間に NameError: name 'MUSIC_BGM' is not defined 定数を足していないか、つづりがちがいます（3-5）。 SOUND_STEP などのつづりちがいも、その音を鳴らす瞬間に同じ NameError で止まります
