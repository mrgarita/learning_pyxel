ゴール

ちがうのは 1 つだけ。step1 はあそぶ画面から作って、あとでタイトルを足したので、 SCENE_PLAY = 0 / SCENE_GAMEOVER = 1 / SCENE_TITLE = 2 と、足した順の番号になっていました。 今回も同じで、あとから足すほど番号が大きくなります。

1. 考え方

1-1. 「いまどの画面か」を数ひとつで覚える

画面が 2 つになると、キーの意味が変わります。 タイトルでの Enter は「始める」、ゲーム中の Enter は「次の面へ」。 同じキーなのに、やることがちがうのです。

これを if の山で書くと、すぐに読めなくなります。そこで、 self.scene に「いまどの画面か」を入れておき、 update() は中身を書かずに、担当のメソッドへ渡すだけにします。

SCENE_TITLE = 0 と名前をつける理由 self.scene に入るのは 0 か 1 です。 なら if self.scene == 0: と書いてもいいはずですが、 半年後の自分が読んで 0 が何かわかりません。
SCENE_TITLE = 0 と名前をつけておくと、 if self.scene == SCENE_TITLE: がそのまま日本語として読めます。 こういう「意味のある名前をつけた数」を定数と呼びます。 DIR_DOWN、U_WALL も同じ仲間です。

1-2. 盤面は、ゲームを始めるときに作る

いまは __init__() の中で load_stage() を呼んでいます。 つまり起動した瞬間に盤面ができているわけです。

でもタイトル画面では、盤面はまだ要りません。そこで load_stage() の呼び出しを __init__() から取り出して、 start_game() という新しいメソッドに移します。 

    def start_game(self):
        """いまの stage_no のステージを読んで、ゲームを始める"""
        self.load_stage(STAGES[self.stage_no])
        self.scene = SCENE_GAME

たった 2 行ですが、これが次のフェーズで効きます。 ステージ選択の画面で面を選んだあとにやることは、この start_game() を呼ぶだけ。 「いまの stage_no から始める」という係を 1 つ作っておくと、 誰が呼んでも同じように始まります。

「係を作る」は、このプロジェクトで何度も出てきました load_stage()（地図をもらって遊べる状態を作る係）、 draw_center()（文字を中央に描く係）、 is_cleared()（クリアしたか答える係）。
やることに名前をつけて外に出しておくと、あとから呼ぶ人が増えても困りません。 start_game() はいま 1 か所（タイトルの Enter）からしか呼ばれませんが、 次のフェーズで 2 か所になります。

3-4. update() を振り分けにする

やることは 3 つです。

  1. いまの def update(self): の行を、def update_game(self): に書き換える （中身は 1 行も動かしません）
  2. その手前に、新しい update() と update_title() を足す
  3. update_game() の中の全クリアの行き先を、タイトルに変える
    def update(self):                                               ← ここから足す
        """フレーム毎の更新処理。いまの画面の担当へ渡す"""
        if self.scene == SCENE_TITLE:
            self.update_title()
        else:
            self.update_game()

    def update_title(self):
        """タイトル画面。Enter でゲームを始める"""
        if pyxel.btnp(pyxel.KEY_RETURN):
            self.start_game()
                                                                    ← ここまで足す
    def update_game(self):                  ← もとの update() の名前を変えただけ
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE        ← load_stage(...) から書き換え
            return

        # ↓ ここから下は、いままでとまったく同じ
        if pyxel.btnp(pyxel.KEY_R):             # いつでも、最初からやり直せる
            self.load_stage(STAGES[self.stage_no])
            return
ここが今回いちばん大事なところです update_game() の中身は、全クリアの 1 行を除いてまったく同じです。 歩く処理、押す処理、クリア判定——ぜんぶそのまま。
「動いているものを、動かさない」。これが安全な書き換えのコツです。 def の行 1 本を書き換えただけなので、 もし動かなくなったら、原因は必ず新しく足した側にあります。

3-5. draw() を振り分けにして、draw_title() を足す

update() とまったく同じ手順です。ただし pyxel.cls() の置き場所に注意。

  1. いまの def draw(self): の行を def draw_game(self): に書き換える
  2. draw_game() の先頭から pyxel.cls(pyxel.COLOR_BLACK) を消す
  3. 手前に、新しい draw() と draw_title() を足す
    def draw(self):                                                 ← ここから足す
        """フレーム毎の描画処理。画面を消してから、担当へ渡す"""
        pyxel.cls(pyxel.COLOR_BLACK)        # 両方の画面で使うので、ここに 1 回だけ

        if self.scene == SCENE_TITLE:
            self.draw_title()
        else:
            self.draw_game()

    def draw_title(self):

        draw_center("SOKOBAN", 30, pyxel.COLOR_YELLOW)

タイトル画面のどこに何を置いているか、図にしました。 横の位置（x）は draw_center() が計算してくれるので、 自分で決めるのは縦の位置（y）だけです。

ゴールのマスだけ、透過色を渡していません pyxel.blt(x + TILE * 3, 66, 0, U_GOAL, V_TILE, TILE, TILE) —— 最後の引数がありません。ゴールのタイルは 8 × 8 ドットぜんぶが絵なので、 透かしたい色がないのです。
ワンコは背景を COLOR_GRAY、リンゴは COLOR_BLACK で描いてあるので、 draw_game() と同じ色を渡します。 ここを間違えると、絵のまわりに四角い枠が出ます。

Enter の行き先がタイトルに変わったので、文字もそう書きます。 draw_game() のいちばん下です。

    def __init__(self):

        pyxel.init(SCREEN_WIDTH, SCREEN_HEIGHT, title="Sokoban")

    def load_stage(self, rows):
        """文字の地図を読んで、壁・主人公・荷物に分ける"""
        self.tiles = []
        self.boxes = []
        self.player_dir = DIR_DOWN      # はじめは下を向いている
        self.walk_timer = 0             # 0 なら止まっている。1～8は歩いている途中
        self.pushing = False            # いまの一歩で荷物を押しているか
        self.cleared = False            # このステージをクリアしたか

        for y in range(len(rows)):
            line = []
            for x in range(len(rows[y])):
                mark = rows[y][x]
                if mark == "@":
                    self.player_x = x
                    self.player_y = y
                    mark = "."          # 主人公の足元は床
                elif mark == "$":
                    self.boxes.append([x, y])
                    mark = "."          # 荷物の下も床
                line.append(mark)
            self.tiles.append(line)

        self.from_x = self.player_x     # 見た目の出発マス
        self.from_y = self.player_y

        # 盤面を画面の中央に置くための、ずらし幅
        board_w = len(self.tiles[0]) * TILE
        board_h = len(self.tiles) * TILE
        self.ox = (SCREEN_WIDTH - board_w) // 2
        self.oy = HUD_HEIGHT + (SCREEN_HEIGHT - HUD_HEIGHT - board_h) // 2

    def update(self):
        """フレーム毎の更新処理。いまの画面の担当へ渡す"""
        if self.scene == SCENE_TITLE:
            self.update_title()
        else:
            self.update_game()

    def update_title(self):
        """タイトル画面。Enter でゲームを始める"""
        if pyxel.btnp(pyxel.KEY_RETURN):
            self.start_game()

    def update_game(self):
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE
            return
        
        if pyxel.btnp(pyxel.KEY_R):             # いつでも、最初からやり直せる
            self.load_stage(STAGES[self.stage_no])
            return

        if self.cleared:                        # クリアした。Enter で次のステージへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.next_stage()
            return
        
        if self.walk_timer > 0:                 # 歩いている途中
            self.walk_timer += 1

            self.try_move(DIR_UP)

        return False

    def move_box(self, x, y, dx, dy):
        """(x, y) にある荷物を、(dx, dy) だけ動かす"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                box[0] += dx
                box[1] += dy
                return

    def on_goal(self, box):
        """その荷物が、ゴールのマスに乗っているか"""
        return self.tiles[box[1]][box[0]] == "O"

    def is_cleared(self):
        """すべての荷物がゴールに乗ったか"""
        return all(self.on_goal(box) for box in self.boxes)

    def next_stage(self):
        """次のステージへ進む。最後だったら全クリア"""
        if self.stage_no + 1 < len(STAGES):
            self.stage_no += 1
            self.load_stage(STAGES[self.stage_no])
        else:
            self.all_cleared = True

    def try_move(self, direction):
        """その向きへ動けるか調べて、動けるときだけ 1 マス進む"""
        self.player_dir = direction     # 動けなくても、向きだけは変える

        dx, dy = MOVES[direction]
        next_x = self.player_x + dx
        next_y = self.player_y + dy

        if self.tiles[next_y][next_x] == "#":   # 行き先が壁なら
            return                              # 何もしないで戻る

        if self.has_box(next_x, next_y):        # 行き先に荷物があるなら
            far_x = next_x + dx                 # 荷物の、1 つ先のマス
            far_y = next_y + dy
            if self.tiles[far_y][far_x] == "#": # その先が壁なら押せない
                return
            if self.has_box(far_x, far_y):      # その先に別の荷物があっても押せない
                return
            self.move_box(next_x, next_y, dx, dy)
            self.pushing = True                 # この一歩は、荷物を押している

        self.player_x = next_x
        self.player_y = next_y
        self.walk_timer = 1                     # ここから 8 フレームかけて歩く

    def slide_pos(self, origin, from_cell, to_cell):
        """出発マスから到着マスへ、いまどこまで来たかをドットで返す"""
        moved = (to_cell - from_cell) * TILE * self.walk_timer // MOVE_FRAMES
        return origin + from_cell * TILE + moved

    def draw(self):
        """フレーム毎の描画処理。画面を消してから、担当へ渡す"""
        pyxel.cls(pyxel.COLOR_BLACK)

        if self.scene == SCENE_TITLE:
            self.draw_title()
        else:
            self.draw_game()

    def draw_title(self):
        """タイトル画面を描く"""
        draw_center("SOKOBAN", 30, pyxel.COLOR_YELLOW)
        draw_center("PUSH THE APPLES", 44, pyxel.COLOR_WHITE)

        # ワンコが、リンゴをゴールへ押していく絵
        x = SCREEN_WIDTH // 2 - TILE * 2
        pyxel.blt(x, 66, 0, DIR_RIGHT * TILE, V_PLAYER_A, TILE, TILE, pyxel.COLOR_GRAY)
        pyxel.blt(x + TILE, 66, 0, U_BOX, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)
        pyxel.blt(x + TILE * 3, 66, 0, U_GOAL, V_TILE, TILE, TILE)

        if is_blink_on():                       # 1 秒のうち 20 フレームだけ見える
            draw_center("PRESS ENTER", 92, pyxel.COLOR_WHITE)

        draw_center("ARROW: MOVE    R: RETRY", 108, pyxel.COLOR_GRAY)

    def draw_game(self):
        """あそんでいる画面を描く"""
        # 壁を、上の行から 1 マスずつ描く
        for y in range(len(self.tiles)):
            for x in range(len(self.tiles[y])):
                mark = self.tiles[y][x]
                if mark == "#":
                    u = U_WALL
                elif mark == "O":
                    u = U_GOAL
                else:
                    u = U_FLOOR
                pyxel.blt(self.ox + x * TILE, self.oy + y * TILE,
                            0, u, V_TILE, TILE, TILE)

        # 荷物。押している 1 つだけは、主人公といっしょにすべる
        dx, dy = MOVES[self.player_dir]
        push_x = self.player_x + dx             # 押した荷物は主人公の目の前にいる
        push_y = self.player_y + dy
        for box in self.boxes:
            if self.pushing and box[0] == push_x and box[1] == push_y:
                bx = self.slide_pos(self.ox, box[0] - dx, box[0])
                by = self.slide_pos(self.oy, box[1] - dy, box[1])
            else:
                bx = self.ox + box[0] * TILE
                by = self.oy + box[1] * TILE
            u = U_BOX
            if self.on_goal(box):       # ゴールに乗っているあいだは別の絵
                u = U_BOX_ON_GOAL
            pyxel.blt(bx, by, 0, u, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)

        # 主人公
        px = self.slide_pos(self.ox, self.from_x, self.player_x)
        py = self.slide_pos(self.oy, self.from_y, self.player_y)
        v = V_PLAYER_A
        if self.walk_timer >= MOVE_FRAMES // 2:     # 歩きの後半は、足を入れ替える
            v = V_PLAYER_B
        pyxel.blt(px, py, 0, self.player_dir * TILE, v, TILE, TILE, pyxel.COLOR_GRAY)

        # 画面の上の表示
        if self.all_cleared:
            draw_center("ALL CLEAR!  ENTER=TITLE", 3, pyxel.COLOR_YELLOW)
        else:
            pyxel.text(2, 3, f"STAGE {self.stage_no + 1}/{len(STAGES)}",
                       pyxel.COLOR_GRAY)
            if self.cleared:
                draw_center("CLEAR!  ENTER", 3, pyxel.COLOR_YELLOW)

6. コードの解説

6-1. 「名前を変えるだけ」が、いちばん安全な書き換え

今回やったことを、行数で分けるとこうなります。

やったこと行数壊れる危険
新しく書いた
（定数・is_blink_on・start_game・振り分け・draw_title）		 約 50 行ここにしかない
名前だけ変えた
（update → update_game、draw → draw_game）		 2 行ほぼない
中身を書き換えた
（全クリアの行き先、ALL CLEAR の文字、cls の移動）		 3 行小さい
そのまま残した
（歩く・押す・クリア判定・地図）		 約 350 行触っていない

350 行は触っていません。だから、もし歩けなくなったら 「歩く処理が壊れた」のではなく「そこまでたどり着いていない」のです。 原因をさがす場所が、最初から決まっている——これが、この書き方のいちばんの得です。

6-2. pyxel.cls() は、振り分けの手前に 1 回だけ

pyxel.cls(pyxel.COLOR_BLACK) は「画面をぜんぶ黒でぬりつぶす」命令です。 Pyxel は前のフレームの絵を消してくれません。自分で消さないと、 動いたものの残像が残りつづけます。

消すのはどの画面でも必ず必要です。だったら draw_title() と draw_game() の両方に書くより、 振り分けの手前に 1 回だけ書くほうが短くて、書き忘れもありません。 

    def draw(self):
        pyxel.cls(pyxel.COLOR_BLACK)        # ← ここに 1 回だけ

        if self.scene == SCENE_TITLE:
            self.draw_title()               # cls は書かない
        else:
            self.draw_game()                # cls は書かない
「共通のことは、分かれる前にやる」 step1 の draw() もまったく同じ形でした。 どの道を通っても必ずやることは、分かれ道の手前に置く。 逆に、片方でしかやらないこと（タイトルの文字、盤面の描画）は、 分かれたあとに置きます。

6-3. タイトル画面では self.tiles がまだ無い

__init__() から load_stage() を消したので、 起動した直後は self.tiles も self.boxes も存在しません。

Python では、self.○○ = ... と代入したその瞬間に self.○○ が生まれます。まだ代入していないものを読もうとすると、 こうなります。 

AttributeError: 'App' object has no attribute 'tiles'

これは「盤面が要らない画面では、盤面を作らない」という設計です。 そのかわり、タイトル画面で draw_game() を呼んでしまうと、 かならずこのエラーで落ちます。
じつはこれはありがたいことです。振り分けを書き間違えたとき、 だまって変な絵が出るのではなく、はっきりエラーで教えてくれるのです。

6-4. 余りで点滅する仕組み

pyxel.frame_count は、起動してからのフレーム数です。 Pyxel は 1 秒に 30 フレーム進むので、10 秒たつと 300 になります。 ずっと増えつづける数なので、そのままでは使えません。

そこで %（余り）を使って、0〜29 をくり返す数に変えます。

数字をいじってみてください BLINK_CYCLE = 60 にすると2 秒に 1 回のゆっくりした点滅、 BLINK_CYCLE = 10 にするとせわしない点滅になります。 BLINK_ON を 15 にすると、見える時間と消える時間が同じ長さ。
「見える時間を長め（20 : 10）にする」のには意図があります。 半々だと点滅が強すぎて、文字が読みにくくなるのです。

6-5. いまは else で足りる。次のフェーズで elif になる

画面が 2 つなので、振り分けは if と else で足ります。

        if self.scene == SCENE_TITLE:
            self.update_title()
        else:                               # タイトルじゃないなら、ゲーム
            self.update_game()

次のフェーズでステージ選択が入って画面が 3 つになると、こうなります。

        if self.scene == SCENE_TITLE:
            self.update_title()
        elif self.scene == SCENE_SELECT:    # ← 1 本増えるだけ
            self.update_select()
        else:
            self.update_game()

増えるのは 2 行だけです。いま振り分けの形にしておいた理由が、ここにあります。 もし update() の中にタイトルの処理を直接書いていたら、 次のフェーズでその中身をほどく作業から始めなければなりません。

7. うまくいかないときは

症状原因と対処
AttributeError: 'App' object has no attribute 'tiles' タイトル画面で draw_game() が呼ばれています。 draw() の振り分けを見てください。 if self.scene == SCENE_TITLE: で self.draw_title() を呼んでいますか（6-3）
起動するといきなりゲームが始まる self.scene = SCENE_TITLE を書いていません。 または SCENE_TITLE と SCENE_GAME の数が逆です （SCENE_TITLE = 0、SCENE_GAME = 1）
タイトルで Enter を押しても始まらない update() の振り分けで self.update_title() を呼んでいますか。 あるいは btn と書いていませんか。btnp です
タイトルの文字が何も出ない draw() から self.draw_title() を呼んでいません。 draw_title() を書いただけでは、誰も呼んでくれません
NameError: name 'is_blink_on' is not defined def is_blink_on() を class App: の中に書いています。 外（draw_center() の下、class の手前）です
PRESS ENTER が点滅せず、ずっと出ている if is_blink_on(): の if を書いていません。 または BLINK_ON が BLINK_CYCLE 以上になっています
PRESS ENTER がまったく出ない is_blink_on() の中の < が > になっていませんか。 frame_count % 30 > 20 だと、ほとんど False です
絵や文字が前のフレームと重なる／残像が出る pyxel.cls(pyxel.COLOR_BLACK) をどこにも書いていません。 draw_game() から消したなら、draw() に足してください（6-2）
タイトルの絵のまわりに四角い枠が出る blt の透過色を渡していません。 ワンコは pyxel.COLOR_GRAY、リンゴは pyxel.COLOR_BLACK。 ゴールは渡しません
タイトルの絵が、ちがう絵になる blt の切り出し位置です。ワンコは DIR_RIGHT * TILE（右向き）と V_PLAYER_A、 リンゴは U_BOX と V_TILE
全クリアのあと Enter で1 面が始まってしまう self.load_stage(...) のままです。 self.scene = SCENE_TITLE に書き換えてください
タイトルに戻ったあと、Enter で何も起きない self.all_cleared = False に戻していません。 True のままだと、ゲームを始めた瞬間に全クリア画面へ行きます
ゲーム中に歩けなくなった／押せなくなった 名前の変更に失敗しています（6-1）。 update_game() の中身は1 行も動かしていないはずです。 def update_game(self): より下の字下げがずれていませんか
IndentationError 同じ原因です。新しいメソッドを足したとき、def は 半角スペース 4 つ、中身は 8 つで字下げします
タイトルに戻ると、また 1 面からしか始められない いまはそれが正しい動きです。 どの面から始めるかを選べるようにするのが、次のフェーズです

8. 次のフェーズ

次はステージ選択です。タイトルで Enter を押したら、 いきなり 1 面が始まるのではなく「どの面から遊ぶか」を選ぶ画面を出します。

次に出てくる考え方 クリアした面だけ選べるようにします。10 面ぜんぶ最初から選べると、 順番に解いていく楽しみがなくなるので、1 つ先までしか開かない形にします。
そのために覚えておくのは、やはり数ひとつだけ。 self.cleared_count（クリアした面の数）です。 これが 3 なら「3 面まで解いた ＝ 4 面まで選べる」。
カーソルの移動は、stage_no をそのまま動かすだけです。 選択画面で「4 面」を指しているというのは、stage_no が 3 だということ。 Enter を押したら、あとは今回作った start_game() を呼ぶだけで始まります。
ひとつ、いまのうちに知っておいてください クリアした記録は self.cleared_count という変数に入れます。 変数はプログラムを終了すると消えます。 つまり次に起動したときは、また 1 面からしか選べません。
記録をファイルに保存して、次に起動しても残るようにすることもできますが、 それは別の話（ファイルの読み書き）になります。 まずは1 回のプレイの中で選べるところまで作ります。
