フェーズ 11 スマホで遊べるようにする

画面に出る十字キーとボタンも、キーボードと同じように受け付ける

トップページ ／ step2 概要 ／ フェーズ 11

ゴール

Pyxel の Web 版をスマホで開くと、画面の下に十字キーとボタン（仮想ゲームパッド）が出ます。 ところが、いまのコードはキーボードしか見ていないので、押しても何も起きません。 このフェーズで、キーボードでもパッドでも、同じように遊べるようにします。

このフェーズで新しく覚えること ① キーとボタンを「組」にして、関数 1 つで調べる（any()）。 ② 十字キーを斜めに押したときの扱いを決める。 ③ Web 版にして、PC のブラウザとスマホで確かめる。
コードは、足すのが 23 行、書き換えが 10 行、handle_key() の中身を書き直します（9 行 → 12 行）。 ゲームの動き（歩く・押す・音）には手を入れません。変えるのは「キーを見ているところ」だけです。

1. 考え方

1-1. パッドを出すのは HTML、押されたかを読むのは Python

仮想ゲームパッドについては、step1 で調べたことが備忘録にまとめてあります。要点は 3 つです。

  • pyxel app2html が作る HTML には、はじめから パッドを出す設定（gamepad: "enabled"）が入っている。 出るのは指で触る端末で開いたときだけで、パソコンの普通の画面では出ない
  • パッドのボタンは、Python からはゲームパッドのボタンに見える。名前は pyxel.GAMEPAD1_BUTTON_…
  • 読み方はキーボードと同じ。pyxel.btn()（押しているあいだ）と pyxel.btnp()（押した瞬間）
画面のパッドPython で読む名前
十字キーの上・下・左・右 pyxel.GAMEPAD1_BUTTON_DPAD_UP ／ _DOWN ／ _LEFT ／ _RIGHT
4 つの丸の下・右・左・上 pyxel.GAMEPAD1_BUTTON_A ／ _B ／ _X ／ _Y
小さいボタンの左・右 pyxel.GAMEPAD1_BUTTON_BACK ／ pyxel.GAMEPAD1_BUTTON_START

つまり、HTML 側は何も直さなくてよく、直すのは Python だけです。 キーを見ている場所で、キーに加えてボタンも見るようにします。

1-2. どのボタンに、どの役目をさせるか

いまのゲームで使っているキーは、矢印・Enter・R・Q の 4 種類です。パッドには、次のように割り当てます。

役目キーボードパッド
歩く ／ カーソルを動かす矢印キー十字キー
決定（始める・次の面へ・タイトルへ）Enter4 つの丸のどれでも
やり直しR小さいボタンの右（START）
ステージ選択へもどるQ小さいボタンの左（BACK）

理由は 3 つです。

  • 丸には文字が書いていない。「下の丸が A」と覚えている人はいません。 そこでどの丸を押しても決定にします。step1 の Candy Hunt をスマホ版にしたときと同じ考え方です
  • やり直しと「選択へもどる」は、押すとそれまでの手数が消えるボタンです。 親指がいつも乗っている丸ではなく、指から離れた小さいボタンに置けば、うっかり押しにくくなります。 倉庫番には「1 手戻す」がないので、なおさらです
  • 名前も合います。START はもう一度スタート、BACK はひとつ前の画面へもどる
概要ページの予定から、割り当てを変えました step2 概要では「A ボタンで決定、B ボタンでやり直し」と予定していました。 これだと、丸に文字がないので「どれが A か」が分かりません。 かといって「どの丸でも決定」にして B もやり直しにすると、クリアのあとに右の丸を押した人は、次の面へ進むつもりで同じ面をやり直すことになります （update_game() は、やり直しを先に調べるからです）。 そこで、やり直しは丸から外しました。概要ページの表も直してあります。

1-3. キーとボタンを「組」にして、1 か所で調べる

たとえば決定は、Enter と 4 つの丸の 5 つのうち、どれか 1 つでも押されたらです。 そのまま or でつなぐと、こうなります。 

        if (pyxel.btnp(pyxel.KEY_RETURN) or pyxel.btnp(pyxel.GAMEPAD1_BUTTON_A)
                or pyxel.btnp(pyxel.GAMEPAD1_BUTTON_B) or pyxel.btnp(pyxel.GAMEPAD1_BUTTON_X)
                or pyxel.btnp(pyxel.GAMEPAD1_BUTTON_Y)):
            self.scene = SCENE_SELECT

長いうえに、決定を見ている場所は4 か所あります（タイトル・選択画面・クリアのあと・全クリアのあと）。 4 か所とも同じ 5 つを書くのは大変ですし、どこか 1 か所で書きもらすと、その画面だけパッドが効きません。

そこで、同じ役目のキーとボタンを 1 本のリストにまとめて名前をつけ（INPUT_OK）、 「リストのどれかが押されたか」を答える関数（pressed()）を 1 つ作ります。すると、さきほどの 4 行はこう書けます。 

        if pressed(INPUT_OK):
            self.scene = SCENE_SELECT
any() は all() の反対側 フェーズ 5 の is_cleared() で、all(self.on_goal(box) for box in self.boxes) と書きました。 「ぜんぶ True なら True」です。any() は同じ書き方で「どれか 1 つでも True なら True」。 any(pyxel.btnp(i) for i in inputs) は、inputs の中身を 1 つずつ i に入れて pyxel.btnp(i) を調べ、1 つでも True があれば True を返します。

押しているあいだを見る pyxel.btn() にも、同じまとめ版 held() を作ります。 歩くとき（押しっぱなしで歩きつづける）は held()、決定やカーソルのように1 回押したら 1 回だけのときは pressed()。 使い分けは、これまでの btn と btnp とまったく同じです。

1-4. 十字キーを斜めに押したら、どうするか

キーボードの矢印キーは 4 つに分かれていますが、画面の十字キーは1 枚の絵です。 pyxel.js（Web 版の Pyxel 本体）を読むと、十字キーの当たり判定は円を 45° ずつ 8 つに分けたものでした。 そのうち斜めの 4 つ（円のちょうど半分）では、2 つの向きが同時に押されたことになります。 十字の腕の上でも、まん中寄りを押すと斜めに入ります。

フェーズ 10 までの handle_key() は、if / elif で下 → 上 → 左 → 右の順に調べていました。 斜めのときは先に書いた「下」か「上」が勝つので、上と下は 135°、左と右は 45° しかありません。 右へ押したつもりで指が少し上にずれると、上へ進みます。 倉庫番では、1 歩のまちがいでリンゴが角に詰まり、やり直すしかなくなることもあります。

そこで、押されている向きが「1 つだけ」のときに進み、2 つ以上のときは進まないことにしました。 まちがった向きへ進むより、何も起きないほうがましだからです。 止まったら、指を少しずらせば進みます。 本物の Web 版で試すと、右から 30° 上を押しても進まず、そこから指を右へずらした瞬間に 1 歩進みました。 キーボードで矢印を 2 つ同時に押したときも、同じように止まります。

3-2. 調べる関数を 2 つ足す

is_blink_on() の下（class App: の上）に足します。draw_center() などと同じく、App の外の関数です。 

def is_blink_on():
    """点滅の「見えている」タイミングなら True を返す"""
    return pyxel.frame_count % BLINK_CYCLE < BLINK_ON

def pressed(inputs):   ← ここから足す
    """inputs のどれかを、いま押した瞬間なら True を返す（btnp のまとめ版）"""
    return any(pyxel.btnp(i) for i in inputs)

def held(inputs):
    """inputs のどれかを、押しているあいだ True を返す（btn のまとめ版）"""
    return any(pyxel.btn(i) for i in inputs)
                       ← ここまで足す（空行も 1 つ）

3-3. タイトルとステージ選択

pyxel.btnp(pyxel.KEY_…) を pressed(INPUT_…) に置きかえます。6 行です。 

    def update_title(self):
        """タイトル画面。Enter でステージ選択へ"""

            self.scene = SCENE_SELECT

    def update_select(self):
        """ステージ選択。矢印でカーソルを動かし、Enter で始める"""
        if pressed(INPUT_LEFT):      ← 書き換え
            self.move_cursor(-1)
        elif pressed(INPUT_RIGHT):   ← 書き換え
            self.move_cursor(1)
        elif pressed(INPUT_UP):      ← 書き換え
            self.move_cursor(-SELECT_COLS)      # 1 段上は、5 つ前
        elif pressed(INPUT_DOWN):    ← 書き換え
            self.move_cursor(SELECT_COLS)       # 1 段下は、5 つ後

        if pressed(INPUT_OK):        ← 書き換え
            self.start_game()

3-4. あそぶ画面の、決定・やり直し・選択へ

update_game() の前半です。4 行置きかえます。最後の 1 行は、and の後ろ半分だけ変わります。 

    def update_game(self):
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pressed(INPUT_OK):                                             ← 書き換え
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE
            return

        if pressed(INPUT_SELECT):               # ステージ選択へもどる          ← 書き換え
            pyxel.stop()                        # 選択画面では BGM を止める
            self.scene = SCENE_SELECT
            return

        if pressed(INPUT_RETRY):                # いつでも、最初からやり直せる   ← 書き換え
            self.start_game()                   # BGM も頭から鳴らしなおす
            return

        if self.cleared:                        # クリアした。間をおいてから、Enter で次のステージへ
            if self.clear_elapsed() >= CLEAR_WAIT and pressed(INPUT_OK):      ← 書き換え（後ろ半分）
                self.next_stage()
            return

3-5. handle_key() を書き直す

歩く向きを決めているところです。中身をまるごと書き直します。いまはこうなっています。 

    def handle_key(self):
        """矢印キーを見て、押された向きへ 1 歩進もうとする"""
        if pyxel.btn(pyxel.KEY_DOWN):
            self.try_move(DIR_DOWN)
        elif pyxel.btn(pyxel.KEY_UP):
            self.try_move(DIR_UP)
        elif pyxel.btn(pyxel.KEY_LEFT):
            self.try_move(DIR_LEFT)
        elif pyxel.btn(pyxel.KEY_RIGHT):
            self.try_move(DIR_RIGHT)

これを、次のようにします。elif が 1 つもないことに気をつけてください。 

    def handle_key(self):
        """押されている向きへ 1 歩進もうとする。斜め（2 つ同時）のときは進まない"""
        dirs = []                               # いま押されている向きを集める
        if held(INPUT_DOWN):
            dirs.append(DIR_DOWN)
        if held(INPUT_UP):
            dirs.append(DIR_UP)
        if held(INPUT_LEFT):
            dirs.append(DIR_LEFT)
        if held(INPUT_RIGHT):
            dirs.append(DIR_RIGHT)
        if len(dirs) == 1:                      # 1 つだけのときに進む
            self.try_move(dirs[0])
  1. 空のリスト dirs を用意する
  2. 下・上・左・右をぜんぶ調べて、押されている向きを dirs に足していく
  3. 集まった数がちょうど 1 つなら、その向き（dirs[0]）へ進もうとする。0 個（何も押していない）と 2 個以上（斜め）は何もしない

try_move() には、これまでと同じ向きの番号（DIR_DOWN など）を 1 つ渡しています。 try_move() から先は 1 文字も変えていません。

STAGES = [STAGE1, STAGE2, STAGE3, STAGE4, STAGE5,
          STAGE6, STAGE7, STAGE8, STAGE9, STAGE10]

def draw_center(text, y, color):
    """文字を、画面の横まんなかに描く"""
    x = (SCREEN_WIDTH - len(text) * 4) // 2
    pyxel.text(x, y, text, color)

def draw_right(text, y, color):
    """文字を、画面の右はしにそろえて描く（右に 2 ドット空ける）"""
    x = SCREEN_WIDTH - len(text) * 4 - 1
    pyxel.text(x, y, text, color)

def is_blink_on():
    """点滅の「見えている」タイミングなら True を返す"""
    return pyxel.frame_count % BLINK_CYCLE < BLINK_ON

def pressed(inputs):
    """inputs のどれかを、いま押した瞬間なら True を返す（btnp のまとめ版）"""
    return any(pyxel.btnp(i) for i in inputs)

def held(inputs):
    """inputs のどれかを、押しているあいだ True を返す（btn のまとめ版）"""
    return any(pyxel.btn(i) for i in inputs)

class App:
    def __init__(self):
        """起動時の設定"""
        pyxel.init(SCREEN_WIDTH, SCREEN_HEIGHT, title="Sokoban")
        pyxel.load("sokoban.pyxres")
        self.scene = SCENE_TITLE        # 起動したら、まずタイトル画面
        self.stage_no = 0               # いま何番目のステージか（0 から数える）
        self.cleared_count = 0          # クリアした面の数（終了すると消える）
        self.all_cleared = False        # 10 個ぜんぶ終わったか
        pyxel.run(self.update, self.draw)

    def opened_count(self):
        """選べる面の数。クリアした数より 1 つ先まで開く"""
        return min(self.cleared_count + 1, len(STAGES))

    def start_game(self):
        """いまの stage_no のステージを読み込んで、BGM を鳴らしはじめる"""
        self.load_stage(STAGES[self.stage_no])
        self.scene = SCENE_GAME
        pyxel.playm(MUSIC_BGM, loop=True)

    def load_stage(self, rows):
        """文字の地図を読んで、壁・主人公・荷物に分ける"""
        self.tiles = []
        self.boxes = []
        self.player_dir = DIR_DOWN      # はじめは下を向いている
        self.walk_timer = 0             # 0 なら止まっている。1～8は歩いている途中
        self.pushing = False            # いまの一歩で荷物を押しているか
        self.cleared = False            # このステージをクリアしたか
        self.steps = 0                  # このステージで歩いた数

        for y in range(len(rows)):
            line = []
            for x in range(len(rows[y])):
                mark = rows[y][x]
                if mark == "@":
                    self.player_x = x
                    self.player_y = y
                    mark = "."          # 主人公の足元は床
                elif mark == "$":
                    self.boxes.append([x, y])
                    mark = "."          # 荷物の下も床
                line.append(mark)
            self.tiles.append(line)

        self.from_x = self.player_x     # 見た目の出発マス
        self.from_y = self.player_y

        # 盤面を画面の中央に置くための、ずらし幅
        board_w = len(self.tiles[0]) * TILE
        board_h = len(self.tiles) * TILE
        self.ox = (SCREEN_WIDTH - board_w) // 2
        self.oy = HUD_HEIGHT + (SCREEN_HEIGHT - HUD_HEIGHT - board_h) // 2

    def update(self):
        """フレーム毎の更新処理。いまの画面の担当へ渡す"""
        if self.scene == SCENE_TITLE:
            self.update_title()
        elif self.scene == SCENE_SELECT:
            self.update_select()
        else:
            self.update_game()

    def update_title(self):
        """タイトル画面。Enter でステージ選択へ"""
        if pressed(INPUT_OK):
            self.scene = SCENE_SELECT

    def update_select(self):
        """ステージ選択。矢印でカーソルを動かし、Enter で始める"""
        if pressed(INPUT_LEFT):
            self.move_cursor(-1)
        elif pressed(INPUT_RIGHT):
            self.move_cursor(1)
        elif pressed(INPUT_UP):
            self.move_cursor(-SELECT_COLS)      # 1 段上は、5 つ前
        elif pressed(INPUT_DOWN):
            self.move_cursor(SELECT_COLS)       # 1 段下は、5 つ後

        if pressed(INPUT_OK):
            self.start_game()

    def move_cursor(self, step):
        """カーソル（stage_no）を step だけ動かす。選べない面へは動かない"""
        next_no = self.stage_no + step
        if 0 <= next_no < self.opened_count():
            self.stage_no = next_no

    def update_game(self):
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pressed(INPUT_OK):
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE
            return

        if pressed(INPUT_SELECT):               # ステージ選択へもどる
            pyxel.stop()                        # 選択画面では BGM を止める
            self.scene = SCENE_SELECT
            return

        if pressed(INPUT_RETRY):                # いつでも、最初からやり直せる
            self.start_game()                   # BGM も頭から鳴らしなおす
            return

        if self.cleared:                        # クリアした。間をおいてから、Enter で次のステージへ
            if self.clear_elapsed() >= CLEAR_WAIT and pressed(INPUT_OK):
                self.next_stage()
            return
        
        if self.walk_timer > 0:                 # 歩いている途中
            self.walk_timer += 1
            if self.walk_timer > MOVE_FRAMES:   # 隣のマスに着いた
                self.walk_timer = 0
                self.from_x = self.player_x     # 見た目を、いまいるマスに合わせる
                self.from_y = self.player_y
                self.pushing = False
                if self.is_cleared():           # 着いた、その瞬間に調べる
                    self.cleared = True
                    self.clear_frame = pyxel.frame_count    # クリアした時刻を覚えておく
                    pyxel.stop()                            # BGM を止めてから
                    pyxel.play(CH_SE, SOUND_CLEAR)          # クリアのジングル
                    # 何面目までクリアしたかを覚える。前の記録より小さくはしない
                    self.cleared_count = max(self.cleared_count, self.stage_no + 1)

        # 止まっていて、まだクリアしていないときだけ、キーを見る    
        if self.walk_timer == 0 and not self.cleared:
            self.handle_key()

    def handle_key(self):
        """押されている向きへ 1 歩進もうとする。斜め（2 つ同時）のときは進まない"""
        dirs = []                               # いま押されている向きを集める
        if held(INPUT_DOWN):
            dirs.append(DIR_DOWN)
        if held(INPUT_UP):
            dirs.append(DIR_UP)
        if held(INPUT_LEFT):
            dirs.append(DIR_LEFT)
        if held(INPUT_RIGHT):
            dirs.append(DIR_RIGHT)
        if len(dirs) == 1:                      # 1 つだけのときに進む
            self.try_move(dirs[0])

    def has_box(self, x, y):
        """そのマスに荷物があるかどうかを答える"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                return True
        return False

    def move_box(self, x, y, dx, dy):
        """(x, y) にある荷物を、(dx, dy) だけ動かす"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                box[0] += dx
                box[1] += dy
                return

    def on_goal(self, box):
        """その荷物が、ゴールのマスに乗っているか"""
        return self.tiles[box[1]][box[0]] == "O"

    def is_cleared(self):
        """すべての荷物がゴールに乗ったか"""
        return all(self.on_goal(box) for box in self.boxes)

    def clear_elapsed(self):
        """クリアしてから何フレームたったか"""
        return pyxel.frame_count - self.clear_frame

    def next_stage(self):
        """次のステージへ進む。最後だったら全クリア"""
        if self.stage_no + 1 < len(STAGES):
            self.stage_no += 1
            self.start_game()                   # 読み込みと BGM は start_game() にまかせる
        else:
            self.all_cleared = True

    def try_move(self, direction):
        """その向きへ動けるか調べて、動けるときだけ 1 マス進む"""
        self.player_dir = direction     # 動けなくても、向きだけは変える

        dx, dy = MOVES[direction]
        next_x = self.player_x + dx
        next_y = self.player_y + dy

        if self.tiles[next_y][next_x] == "#":   # 行き先が壁なら
            return                              # 何もしないで戻る

        if self.has_box(next_x, next_y):        # 行き先に荷物があるなら
            far_x = next_x + dx                 # 荷物の、1 つ先のマス
            far_y = next_y + dy
            if self.tiles[far_y][far_x] == "#": # その先が壁なら押せない
                return
            if self.has_box(far_x, far_y):      # その先に別の荷物があっても押せない
                return
            self.move_box(next_x, next_y, dx, dy)
            self.pushing = True                 # この一歩は、荷物を押している
            if self.tiles[far_y][far_x] == "O": # 押した先がゴールなら
                pyxel.play(CH_SE, SOUND_GOAL)   # 乗せた音
            else:
                pyxel.play(CH_SE, SOUND_PUSH)   # 押した音

        self.player_x = next_x
        self.player_y = next_y
        self.walk_timer = 1                     # ここから 8 フレームかけて歩く
        self.steps += 1                         # 動けたときだけ、1 歩と数える
        pyxel.play(CH_STEP, SOUND_STEP)         # 歩いた音（押したときも鳴る）

    def slide_pos(self, origin, from_cell, to_cell):
        """出発マスから到着マスへ、いまどこまで来たかをドットで返す"""
        moved = (to_cell - from_cell) * TILE * self.walk_timer // MOVE_FRAMES
        return origin + from_cell * TILE + moved

    def draw(self):
        """フレーム毎の描画処理。画面を消してから、担当へ渡す"""
        pyxel.cls(pyxel.COLOR_BLACK)    # 各画面で使うので、ここに 1 回だけ

        if self.scene == SCENE_TITLE:
            self.draw_title()
        elif self.scene == SCENE_SELECT:
            self.draw_select()
        else:
            self.draw_game()

    def draw_title(self):
        """タイトル画面を描く"""
        draw_center("SOKOBAN", 30, pyxel.COLOR_YELLOW)
        draw_center("PUSH THE APPLES", 44, pyxel.COLOR_WHITE)

        # ワンコが、リンゴをゴールへ押していく絵
        x = SCREEN_WIDTH // 2 - TILE * 2
        pyxel.blt(x, 66, 0, DIR_RIGHT * TILE, V_PLAYER_A, TILE, TILE, pyxel.COLOR_GRAY)
        pyxel.blt(x + TILE, 66, 0, U_BOX, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)
        pyxel.blt(x + TILE * 3, 66, 0, U_GOAL, V_TILE, TILE, TILE)

        if is_blink_on():               # 1 秒のうち 20 フレームだけ見える
            draw_center("PRESS ENTER", 92, pyxel.COLOR_WHITE)

        draw_center("ARROW: MOVE  R: RETRY  Q: SELECT", 108, pyxel.COLOR_GRAY)

    def draw_select(self):
        """ステージ選択の画面を描く"""
        draw_center("SELECT STAGE", 16, pyxel.COLOR_YELLOW)

        for no in range(len(STAGES)):
            col = no % SELECT_COLS              # 左から何番目か（0～4）
            row = no // SELECT_COLS             # 上から何段目か（0～1）
            x = 18 + col * 26
            y = 36 + row * 24

            if no < self.cleared_count:         # クリアした面
                color = pyxel.COLOR_LIME
            elif no == self.cleared_count:      # 次に挑む 1 面
                color = pyxel.COLOR_WHITE
            else:                               # まだ選べない面
                color = pyxel.COLOR_NAVY

            pyxel.rectb(x, y, 20, 16, color)
            label = f"{no + 1}"
            pyxel.text(x + (20 - len(label) * 4) // 2, y + 5, label, color)

            if no == self.stage_no:             # カーソルは、ひとまわり大きい枠
                pyxel.rectb(x - 2, y - 2, 24, 20, pyxel.COLOR_YELLOW)

        draw_center("ARROW: CHOOSE    ENTER: START", 96, pyxel.COLOR_GRAY)

    def draw_game(self):
        """あそんでいる画面を描く"""

        # 壁を、上の行から 1 マスずつ描く
        for y in range(len(self.tiles)):
            for x in range(len(self.tiles[y])):
                mark = self.tiles[y][x]
                if mark == "#":
                    u = U_WALL
                elif mark == "O":
                    u = U_GOAL
                else:
                    u = U_FLOOR
                pyxel.blt(self.ox + x * TILE, self.oy + y * TILE,
                            0, u, V_TILE, TILE, TILE)

        # クリアした直後は、リンゴから輪が広がる。リンゴの下から出てくるように、先に描く
        if self.cleared and self.clear_elapsed() < CLEAR_WAIT:
            r = self.clear_elapsed() // 2       # 2 フレームに 1 ドットずつ大きく
            for box in self.boxes:
                cx = self.ox + box[0] * TILE + TILE // 2
                cy = self.oy + box[1] * TILE + TILE // 2
                pyxel.circb(cx, cy, r, pyxel.COLOR_YELLOW)

        # 荷物。押している 1 つだけは、主人公といっしょにすべる
        dx, dy = MOVES[self.player_dir]
        push_x = self.player_x + dx             # 押した荷物は主人公の目の前にいる
        push_y = self.player_y + dy
        for box in self.boxes:
            if self.pushing and box[0] == push_x and box[1] == push_y:
                bx = self.slide_pos(self.ox, box[0] - dx, box[0])
                by = self.slide_pos(self.oy, box[1] - dy, box[1])
            else:
                bx = self.ox + box[0] * TILE
                by = self.oy + box[1] * TILE
            u = U_BOX
            if self.on_goal(box):       # ゴールに乗っているあいだは別の絵
                u = U_BOX_ON_GOAL
            pyxel.blt(bx, by, 0, u, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)

        # 主人公
        px = self.slide_pos(self.ox, self.from_x, self.player_x)
        py = self.slide_pos(self.oy, self.from_y, self.player_y)
        v = V_PLAYER_A
        if self.walk_timer >= MOVE_FRAMES // 2:     # 歩きの後半は、足を入れ替える
            v = V_PLAYER_B
        d = self.player_dir
        if self.cleared and self.clear_elapsed() >= CLEAR_WAIT:
            d = DIR_DOWN                        # こちらを向いて
            if self.clear_elapsed() % 16 < 8:
                py -= 2                         # ぴょんと跳ねる
        pyxel.blt(px, py, 0, d * TILE, v, TILE, TILE, pyxel.COLOR_GRAY)

        # 画面の上の表示
        if self.all_cleared:
            draw_center("ALL CLEAR!  ENTER=TITLE", 3, pyxel.COLOR_YELLOW)
        else:
            pyxel.text(2, 3, f"STAGE {self.stage_no + 1}/{len(STAGES)}",
                       pyxel.COLOR_GRAY)
            draw_right(f"STEPS {self.steps}", 3, pyxel.COLOR_GRAY)
            if self.cleared and self.clear_elapsed() >= CLEAR_WAIT:
                draw_center("CLEAR!  ENTER", 3, pyxel.COLOR_YELLOW)

6. コードの解説

6-1. any() と all()：「どれか」と「ぜんぶ」

書き方True になるとき使った場所
all(… for … in …)ぜんぶ True のときis_cleared()：リンゴがぜんぶゴールに乗った（フェーズ 5）
any(… for … in …)どれか 1 つでも True のときpressed()：組のキーとボタンのどれかを押した（このフェーズ）

pressed(INPUT_OK) を for で書きくだすと、こうなります。1 つでも見つかったら、その場で True を返して終わりです。 

def pressed(inputs):
    for i in inputs:
        if pyxel.btnp(i):
            return True         # 1 つ見つかれば、あとは調べない
    return False                # 最後まで見つからなかった

リストに入っているのは、じつはただの数です（pyxel.KEY_RETURN は 13）。 pyxel.btnp() は数を受け取るので、リストのまま渡すと TypeError になります（7）。 1 つずつ取り出して渡すのが for i in inputs の役目です。

6-2. elif は「最初の 1 つ」、if を並べると「ぜんぶ」

フェーズ 10 までの handle_key() は、elif で最初に当たった 1 つだけを見ていました。 これだと「ほかにも押されていたか」が分かりません。 新しい handle_key() は if を 4 つ並べて、ぜんぶ調べてから決めます。

押しているものdirsどうなる
何も押していない[]何もしない
右だけ[DIR_RIGHT]（[3]）右へ 1 歩
上と右（斜め）[DIR_UP, DIR_RIGHT]（[1, 3]）何もしない
↑ キーと十字キーの上を同時に[DIR_UP]上へ 1 歩（同じ向きは 1 つと数える）

最後の行に注目してください。held(INPUT_UP) は、キーとボタンのどちらで押しても 1 回 True になるだけなので、 同じ向きが 2 つ入ることはありません。「集めてから、数で決める」書き方は、こういう場面でよく使います。

6-3. 歩くのは held()、それ以外は pressed()

置きかえるとき、btn だったところは held、btnp だったところは pressed にしました。 逆にすると、こうなります（どちらもエラーは出ません）。

まちがえた場所実際に試した結果
handle_key() で pressed()右を 40 フレーム押しっぱなしにしても 1 歩だけ。押しなおさないと次の 1 歩が出ない
選択画面で held()右を 10 フレーム押しただけで、カーソルが1 面から 10 面まで一気に飛ぶ

6-4. 選択画面は elif のままでよい

選択画面のカーソルも、十字キーの斜めでは 2 つの向きが入ります。こちらは elif のままなので、 押した瞬間が斜めなら、先に書いた左右が勝ちます（試すと、上＋右で右へ 1 つ動きました）。

それでも直さないのは、カーソルはすぐに戻せるからです。まちがえても、反対へ 1 回押せば元どおり。 倉庫番の 1 歩のように取り返しがつかないところだけ、慎重にしました。

6-5. HTML には手を入れていない

パッドを出す・押された場所を調べる、という仕事は pyxel app2html が作った HTML（と、そこから読み込む pyxel.js）がやっています。 Python のコードは「GAMEPAD1_BUTTON_… が押されたか」を聞くだけです。 そのため、同じコードが、PC（キーボード）・USB のゲームパッド・スマホの画面の 3 つで動きます。

症状原因と対処
起動した瞬間に SyntaxError: invalid syntax. Perhaps you forgot a comma? INPUT_OK の中の行の終わりのカンマが抜けています（3-1）。エラーに出た行の終わり（コメントの前）に , を足します

右にしか進まない（下・上・左は、向きも変わらない） if len(dirs) == 1: の字下げが深く、if held(INPUT_RIGHT): の中に入っています。dirs = [] と同じ深さ（スペース 8 つ）に（3-5）
斜めに押すと、上（か下）へ進んでしまう handle_key() に elif が残っているか、len(dirs) == 1 が >= 1 になっています（6-2）
