フェーズ 8 ステージ選択

クリアした面だけ選べるようにする

トップページ ／ step2 概要 ／ フェーズ 8

ゴール

タイトルで Enter を押したら、いきなり 1 面が始まるのではなく、 「どの面から遊ぶか」を選ぶ画面を出します。 ただし選べるのはクリアした面と、その次の 1 面だけ。 順番に解いていく楽しみは残したまま、解いた面はいつでも遊び直せる形にします。

ゲーム中に Q を押すと、選択画面へ戻れるようにもします。 画面のつながりは、次のようになります。

地図は、作り直した 4 面が入っています この下のできあがりのコードの STAGE7 〜 STAGE10 は、 番外ページで作り直した地図です。 STAGE10 だけは、番外ページの地図をもとに自分で作り直したもの （荷物 7 つ・押し 67 回）を載せています。
地図の中身は、どれを入れていてもこのフェーズのコードには関係ありません。

1. 考え方

1-1. 覚えるのは「何面までクリアしたか」の数ひとつ

「どの面が選べるか」を覚えておく方法を考えます。 すぐ思いつくのは、面ごとに「クリアしたか」を覚えておくやり方です。 

cleared = [True, True, True, False, False, False, False, False, False, False]

でも、このゲームは1 つ先までしか開かないので、選べる面はかならず前から順番につながっています。 「1 面と 3 面はクリアしたけど 2 面はまだ」ということは起こりません。 だったら、覚えるのは「前から何面クリアしたか」の数ひとつで足ります。 

self.cleared_count = 3      # 3 面までクリアした

これが 3 のとき、選択画面はこう見えます。

色の分け方を見てください。cleared_count が 3 なら、クリアした面は no が 0・1・2 の 3 つ。 そして次に挑む面の no は、ちょうど 3——cleared_count と同じ数です。 番号を 0 から数えているおかげで、比べるだけで色が決まります。 

            if no < self.cleared_count:         # クリアした面
                color = pyxel.COLOR_LIME
            elif no == self.cleared_count:      # 次に挑む 1 面
                color = pyxel.COLOR_WHITE
            else:                               # まだ選べない面
                color = pyxel.COLOR_NAVY

1-2. 選べる面の数は min() で上限を作る

選べる面の数は「クリアした数 ＋ 1」です。3 面までクリアしたら、4 面まで選べます。

ただし、10 面ぜんぶクリアしたときに困ります。10 + 1 で 11 面まで選べることになりますが、 11 面はありません。そこで min() で上限をつけます。 

    def opened_count(self):
        """選べる面の数。クリアした数より 1 つ先まで開く"""
        return min(self.cleared_count + 1, len(STAGES))

min() は step1 で使いました step1 フェーズ 2 で、男の子が画面の外へ出ないように max(0, min(self.boy_x, SCREEN_WIDTH - BOY_SIZE)) と書きました。 「これより大きくならないようにする」のが min()、 「これより小さくならないようにする」のが max() です。 このフェーズでは、両方とも出てきます。

1-3. カーソルは stage_no そのもの

選択画面の黄色い枠（カーソル）の位置を覚える変数は、新しく作りません。 いまある self.stage_no をそのまま動かします。 カーソルが「4」を指しているとき、stage_no は 3 です。

こうしておくと、うれしいことが 2 つあります。

  • Enter を押したら、フェーズ 7 で作った start_game() を呼ぶだけで、その面が始まる （start_game() は「いまの stage_no から始める係」でした）
  • ゲーム中に Q で戻ってきたとき、カーソルが「いま遊んでいた面」に最初から乗っている （何も書かなくても、そうなる）

1-4. 番号から、並べる位置を出す

10 面を横 5 つ × 2 段に並べます。 no が 7 の面は、左から何番目・上から何段目でしょうか。

余り（%）が「左から何番目」、切り捨て割り算（//）が「上から何段目」。 5 で割るのは、横に 5 つ並べるからです。この 5 を SELECT_COLS という定数にしておきます。

2. このフェーズで使う機能

機能役割
min(a, b) / max(a, b) 小さいほう／大きいほうを返す。step1 フェーズ 2 と同じ。 選べる面の上限と、クリア記録を減らさないために使う
% と // 番号から、左から何番目（余り）・上から何段目（切り捨て）を出す。フェーズ 7 の点滅と同じ
0 <= n < m 比較を 2 つつなげて書ける（Python の書き方）。「n が 0 以上で、しかも m より小さい」。 このフェーズで初めて出ます（6-3）
pyxel.rectb(x, y, w, h, col) 枠だけの四角を描く（中はぬらない）。左上が (x, y)、幅 w・高さ h。 中までぬるのは pyxel.rect（b がない）。このフェーズで初めて出ます
pyxel.btnp 押した瞬間だけ True。カーソルは1 回押すと 1 マス動いてほしいので btnp

    def load_stage(self, rows):
        """文字の地図を読んで、壁・主人公・荷物に分ける"""
        self.tiles = []
        self.boxes = []
        self.player_dir = DIR_DOWN      # はじめは下を向いている
        self.walk_timer = 0             # 0 なら止まっている。1～8は歩いている途中
        self.pushing = False            # いまの一歩で荷物を押しているか
        self.cleared = False            # このステージをクリアしたか

        for y in range(len(rows)):
            line = []
            for x in range(len(rows[y])):
                mark = rows[y][x]
                if mark == "@":
                    self.player_x = x
                    self.player_y = y
                    mark = "."          # 主人公の足元は床
                elif mark == "$":
                    self.boxes.append([x, y])
                    mark = "."          # 荷物の下も床
                line.append(mark)
            self.tiles.append(line)

        self.from_x = self.player_x     # 見た目の出発マス
        self.from_y = self.player_y

        # 盤面を画面の中央に置くための、ずらし幅
        board_w = len(self.tiles[0]) * TILE
        board_h = len(self.tiles) * TILE
        self.ox = (SCREEN_WIDTH - board_w) // 2
        self.oy = HUD_HEIGHT + (SCREEN_HEIGHT - HUD_HEIGHT - board_h) // 2

    def update(self):
        """フレーム毎の更新処理。いまの画面の担当へ渡す"""
        if self.scene == SCENE_TITLE:
            self.update_title()
        elif self.scene == SCENE_SELECT:
            self.update_select()
        else:
            self.update_game()

    def update_title(self):
        """タイトル画面。Enter でステージ選択へ"""
        if pyxel.btnp(pyxel.KEY_RETURN):
            self.scene = SCENE_SELECT

    def update_select(self):
        """ステージ選択。矢印でカーソルを動かし、Enter で始める"""
        if pyxel.btnp(pyxel.KEY_LEFT):
            self.move_cursor(-1)
        elif pyxel.btnp(pyxel.KEY_RIGHT):
            self.move_cursor(1)
        elif pyxel.btnp(pyxel.KEY_UP):
            self.move_cursor(-SELECT_COLS)      # 1 段上は、5 つ前
        elif pyxel.btnp(pyxel.KEY_DOWN):
            self.move_cursor(SELECT_COLS)       # 1 段下は、5 つ後

        if pyxel.btnp(pyxel.KEY_RETURN):
            self.start_game()

    def move_cursor(self, step):
        """カーソル（stage_no）を step だけ動かす。選べない面へは動かない"""
        next_no = self.stage_no + step
        if 0 <= next_no < self.opened_count():
            self.stage_no = next_no

    def update_game(self):
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE
            return

        if pyxel.btnp(pyxel.KEY_Q):             # ステージ選択へもどる
            self.scene = SCENE_SELECT
            return

        if pyxel.btnp(pyxel.KEY_R):             # いつでも、最初からやり直せる
            self.load_stage(STAGES[self.stage_no])
            return

        if self.cleared:                        # クリアした。Enter で次のステージへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.next_stage()
            return
        
        if self.walk_timer > 0:                 # 歩いている途中
            self.walk_timer += 1
            if self.walk_timer > MOVE_FRAMES:   # 隣のマスに着いた
                self.walk_timer = 0
                self.from_x = self.player_x     # 見た目を、いまいるマスに合わせる
                self.from_y = self.player_y
                self.pushing = False
                if self.is_cleared():           # 着いた、その瞬間に調べる
                    self.cleared = True
                    # 何面目までクリアしたかを覚える。前の記録より小さくはしない
                    self.cleared_count = max(self.cleared_count, self.stage_no + 1)

        # 止まっていて、まだクリアしていないときだけ、キーを見る    
        if self.walk_timer == 0 and not self.cleared:
            self.handle_key()

    def handle_key(self):
        """矢印キーを見て、押された向きへ 1 歩進もうとする"""
        if pyxel.btn(pyxel.KEY_DOWN):
            self.try_move(DIR_DOWN)
        elif pyxel.btn(pyxel.KEY_UP):
            self.try_move(DIR_UP)
        elif pyxel.btn(pyxel.KEY_LEFT):
            self.try_move(DIR_LEFT)
        elif pyxel.btn(pyxel.KEY_RIGHT):
            self.try_move(DIR_RIGHT)

    def has_box(self, x, y):
        """そのマスに荷物があるかどうかを答える"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                return True
        return False

    def move_box(self, x, y, dx, dy):
        """(x, y) にある荷物を、(dx, dy) だけ動かす"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                box[0] += dx
                box[1] += dy
                return

    def on_goal(self, box):
        """その荷物が、ゴールのマスに乗っているか"""
        return self.tiles[box[1]][box[0]] == "O"

    def is_cleared(self):
        """すべての荷物がゴールに乗ったか"""
        return all(self.on_goal(box) for box in self.boxes)

    def next_stage(self):
        """次のステージへ進む。最後だったら全クリア"""
        if self.stage_no + 1 < len(STAGES):
            self.stage_no += 1
            self.load_stage(STAGES[self.stage_no])
        else:
            self.all_cleared = True

    def try_move(self, direction):
        """その向きへ動けるか調べて、動けるときだけ 1 マス進む"""
        self.player_dir = direction     # 動けなくても、向きだけは変える

        dx, dy = MOVES[direction]
        next_x = self.player_x + dx
        next_y = self.player_y + dy

        if self.tiles[next_y][next_x] == "#":   # 行き先が壁なら
            return                              # 何もしないで戻る

        if self.has_box(next_x, next_y):        # 行き先に荷物があるなら
            far_x = next_x + dx                 # 荷物の、1 つ先のマス
            far_y = next_y + dy
            if self.tiles[far_y][far_x] == "#": # その先が壁なら押せない
                return
            if self.has_box(far_x, far_y):      # その先に別の荷物があっても押せない
                return
            self.move_box(next_x, next_y, dx, dy)
            self.pushing = True                 # この一歩は、荷物を押している

        self.player_x = next_x
        self.player_y = next_y
        self.walk_timer = 1                     # ここから 8 フレームかけて歩く

    def slide_pos(self, origin, from_cell, to_cell):
        """出発マスから到着マスへ、いまどこまで来たかをドットで返す"""
        moved = (to_cell - from_cell) * TILE * self.walk_timer // MOVE_FRAMES
        return origin + from_cell * TILE + moved

    def draw(self):
        """フレーム毎の描画処理。画面を消してから、担当へ渡す"""
        pyxel.cls(pyxel.COLOR_BLACK)    # 各画面で使うので、ここに 1 回だけ

        if self.scene == SCENE_TITLE:
            self.draw_title()
        elif self.scene == SCENE_SELECT:
            self.draw_select()
        else:
            self.draw_game()

    def draw_title(self):
        """タイトル画面を描く"""
        draw_center("SOKOBAN", 30, pyxel.COLOR_YELLOW)
        draw_center("PUSH THE APPLES", 44, pyxel.COLOR_WHITE)

        # ワンコが、リンゴをゴールへ押していく絵
        x = SCREEN_WIDTH // 2 - TILE * 2
        pyxel.blt(x, 66, 0, DIR_RIGHT * TILE, V_PLAYER_A, TILE, TILE, pyxel.COLOR_GRAY)
        pyxel.blt(x + TILE, 66, 0, U_BOX, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)
        pyxel.blt(x + TILE * 3, 66, 0, U_GOAL, V_TILE, TILE, TILE)

        if is_blink_on():               # 1 秒のうち 20 フレームだけ見える
            draw_center("PRESS ENTER", 92, pyxel.COLOR_WHITE)

        draw_center("ARROW: MOVE  R: RETRY  Q: SELECT", 108, pyxel.COLOR_GRAY)

    def draw_select(self):
        """ステージ選択の画面を描く"""
        draw_center("SELECT STAGE", 16, pyxel.COLOR_YELLOW)

        for no in range(len(STAGES)):
            col = no % SELECT_COLS              # 左から何番目か（0～4）
            row = no // SELECT_COLS             # 上から何段目か（0～1）
            x = 18 + col * 26
            y = 36 + row * 24

            if no < self.cleared_count:         # クリアした面
                color = pyxel.COLOR_LIME
            elif no == self.cleared_count:      # 次に挑む 1 面
                color = pyxel.COLOR_WHITE
            else:                               # まだ選べない面
                color = pyxel.COLOR_NAVY

            pyxel.rectb(x, y, 20, 16, color)
            label = f"{no + 1}"
            pyxel.text(x + (20 - len(label) * 4) // 2, y + 5, label, color)

            if no == self.stage_no:             # カーソルは、ひとまわり大きい枠
                pyxel.rectb(x - 2, y - 2, 24, 20, pyxel.COLOR_YELLOW)

        draw_center("ARROW: CHOOSE    ENTER: START", 96, pyxel.COLOR_GRAY)

    def draw_game(self):
        """あそんでいる画面を描く"""

        # 壁を、上の行から 1 マスずつ描く
        for y in range(len(self.tiles)):
            for x in range(len(self.tiles[y])):
                mark = self.tiles[y][x]
                if mark == "#":
                    u = U_WALL
                elif mark == "O":
                    u = U_GOAL
                else:
                    u = U_FLOOR
                pyxel.blt(self.ox + x * TILE, self.oy + y * TILE,
                            0, u, V_TILE, TILE, TILE)

        # 荷物。押している 1 つだけは、主人公といっしょにすべる
        dx, dy = MOVES[self.player_dir]
        push_x = self.player_x + dx             # 押した荷物は主人公の目の前にいる
        push_y = self.player_y + dy
        for box in self.boxes:
            if self.pushing and box[0] == push_x and box[1] == push_y:
                bx = self.slide_pos(self.ox, box[0] - dx, box[0])
                by = self.slide_pos(self.oy, box[1] - dy, box[1])
            else:
                bx = self.ox + box[0] * TILE
                by = self.oy + box[1] * TILE
            u = U_BOX
            if self.on_goal(box):       # ゴールに乗っているあいだは別の絵
                u = U_BOX_ON_GOAL
            pyxel.blt(bx, by, 0, u, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)

        # 主人公
        px = self.slide_pos(self.ox, self.from_x, self.player_x)
        py = self.slide_pos(self.oy, self.from_y, self.player_y)
        v = V_PLAYER_A
        if self.walk_timer >= MOVE_FRAMES // 2:     # 歩きの後半は、足を入れ替える
            v = V_PLAYER_B
        pyxel.blt(px, py, 0, self.player_dir * TILE, v, TILE, TILE, pyxel.COLOR_GRAY)

        # 画面の上の表示
        if self.all_cleared:
            draw_center("ALL CLEAR!  ENTER=TITLE", 3, pyxel.COLOR_YELLOW)
        else:
            pyxel.text(2, 3, f"STAGE {self.stage_no + 1}/{len(STAGES)}",
                       pyxel.COLOR_GRAY)
            if self.cleared:
                draw_center("CLEAR!  ENTER", 3, pyxel.COLOR_YELLOW)

6. コードの解説

6-1. 数ひとつで足りるのは「順番にしか開かない」から

1-1 で、面ごとの True / False のリストではなく、 数ひとつで覚えることにしました。これは「1 つ先までしか開かない」という決まりがあるからできたことです。

決まりクリアした面の並び方覚え方
1 つ先までしか開かない（今回） かならず前から順番につながる（1・2・3 …） 数ひとつ（cleared_count）
最初から好きな面を選べる とびとびになる（1・4・7 だけ、など） 面ごとのリスト（[True, False, …]）

ゲームの決まりが、データの持ち方を決めます。 決まりを変えたくなったら、データの持ち方も変える——その順番で考えるとうまくいきます。

6-2. 記録は「クリアした瞬間」に、max() でつける

記録をつける 1 行には、気をつけたところが 2 つあります。

max() を使わないと、遊び直しで記録が減る

max() を使わず self.cleared_count = self.stage_no + 1 と書いたとします。 5 面までクリアしたあとで、2 面を遊び直してクリアすると…… 

# 5 面までクリアしたあと（cleared_count は 5）、2 面（stage_no は 1）を解き直した
self.cleared_count = self.stage_no + 1      # 1 + 1 = 2 …… 5 だった記録が 2 に下がる

記録が 5 から 2 に下がり、4〜6 面が閉じてしまいます（実際に動かして確かめました）。 max(self.cleared_count, self.stage_no + 1) なら、いまの記録と比べて大きいほうを残すので、 遊び直しで記録が減ることはありません。

next_stage() に書くと、2 つの道で記録がつかない

「クリアしたら次の面へ進む」のだから、next_stage() の中で記録をつけてもよさそうに見えます。 でも、そうすると記録がつかない道が 2 つできます。

こんなときnext_stage() に書いた場合クリアの瞬間に書いた場合（今回）
CLEAR! が出たところで Q を押した next_stage() を通らないので記録がつかない。次の面が開かない もう記録済み。次の面が白になっている
10 面をクリアした 最後の面は stage_no += 1 の道を通らないので、記録が 9 のまま。10 面が黄緑にならない 10 になる

「クリアした」という出来事が起きた、その場所で記録する。 あとの処理（次へ進む・選択画面へ戻る・全クリア）がどの道を通っても、記録は必ずついています。

6-3. 0 <= next_no < self.opened_count() —— 比較を 2 つつなげる

move_cursor() の if は、比較が 2 つつながっています。 

        if 0 <= next_no < self.opened_count():

これは Python の書き方で、次の 2 つを and でつないだのと同じ意味です。 数学の 0 ≦ n ＜ m と同じ形で書けます。 

        if 0 <= next_no and next_no < self.opened_count():
0 <= を書き忘れても、エラーは出ません Python のリストは、マイナスの番号を「後ろから数える」と決まっています。 STAGES[-1] は最後の地図（STAGE10）、STAGES[-6] は STAGE5 です。
そのため 0 <= を書き忘れると、エラーにならずに、おかしな動きだけが起きます。 実際に試すと、「1」で左を押したところで黄色い枠が消え（stage_no が -1）、 さらに上を押して Enter を押すとSTAGE -5/10 と表示されて 5 面が始まりました。
だまって壊れるのがいちばん怖いので、範囲の両はしをきちんと確かめます。

6-4. Q を全クリアのあとに置く理由

フェーズ 6 で、update_game() の頭に早い return を並べました。 そのとき「並べた順が、そのまま優先順位になる」と説明しました。 Q を足したいまは、こう並んでいます。

順番調べること当てはまったら
1全クリアしたか（all_cleared）Enter だけ見て return
2Q を押したか（今回）選択画面へ行って return
3R を押したかやり直して return
4クリアしたか（cleared）Enter だけ見て return
5（ここまで来たら）ふつうに歩く・押す　

もし Q をいちばん上に置くと、ALL CLEAR! が出ているあいだにも Q が効きます。 すると all_cleared が True のまま選択画面へ行き、 次にどの面を選んでも、始まった瞬間に ALL CLEAR! が出てしまいます （all_cleared を False に戻すのは、全クリアの Enter の中だけだからです。実際に確かめました）。

全クリアの画面では Enter 以外を受け付けない—— だから全クリアの判定をいちばん上に置き、Q はそのすぐ下です。 逆に CLEAR!（1 面ぶんのクリア）のあとの Q は効いてほしいので、 cleared の判定より上に置いています。

7. うまくいかないときは

症状原因と対処
タイトルで Enter を押すと、AttributeError: 'App' object has no attribute 'tiles' draw() に elif を足していません。 選択画面なのに else の draw_game() が呼ばれ、まだ無い盤面を描こうとしています （フェーズ 7 の 6-3）
タイトルで Enter を押すと、AttributeError: 'App' object has no attribute 'cleared' update() に elif を足していません。 選択画面なのに update_game() が呼ばれています
タイトルで Enter を押すと、選択画面を通らずに 1 面が始まる update_title() が self.start_game() のままです。 self.scene = SCENE_SELECT に書き換えてください
矢印を押すと TypeError: '<' not supported between instances of 'int' and 'method' self.opened_count のうしろの () がありません。 () がないと「関数を呼んだ答え」ではなく「関数そのもの」と比べることになります
選択画面で矢印を押しても、黄色い枠が動かない 最初はそれが正しい動きです（1 面しか開いていない）。 1 面をクリアしてから確かめてください。上下は6 面まで開いてから（5 の「確かめるための近道」が便利です）
1 面をクリアして Q で戻っても、「2」が白にならない 記録の 2 行を next_stage() に書いていませんか（6-2）。 update_game() の if self.is_cleared(): の中です
前の面を遊び直すと、開いていた面が閉じる max() を使っていません（6-2）。 self.cleared_count = max(self.cleared_count, self.stage_no + 1)
「1」で左を押すと黄色い枠が消える／STAGE 0/10 のような表示で始まる move_cursor() の 0 <= を書き忘れています（6-3）
ALL CLEAR! のあと、どの面を選んでも ALL CLEAR! になる Q の if を 全クリアの if より上に置いています（6-4）
上下で 1 つずつしか動かない／左右と同じ動きになる 上下の move_cursor() に SELECT_COLS ではなく 1 を渡しています。 上は -SELECT_COLS、下は SELECT_COLS です
マスが 1 列に並んでしまう／重なる col と row の % と // が逆です。 列（左から何番目）が余り、段（上から何段目）が切り捨てです
数字が枠からずれる pyxel.text の x に枠の左はし x を足していないか、 y + 5 の + 5 がありません
NameError: name 'SELECT_COLS' is not defined 定数を足していないか、つづりがちがいます（SELECT_COL など）
起動し直すと、また「1」しか選べない いまはそれが正しい動きです。記録は変数なので、終了すると消えます（次のフェーズの下の note）

8. 次のフェーズ
