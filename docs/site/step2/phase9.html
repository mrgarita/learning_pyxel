フェーズ 9 手数の表示とクリア演出

何歩で解いたかを出し、クリアの瞬間に間をつくる

トップページ ／ step2 概要 ／ フェーズ 9

ゴール

遊んでいるあいだ、画面の右上に何歩歩いたか（STEPS）を出します。 そして最後のリンゴがゴールに乗った瞬間、リンゴから黄色い輪が広がり、 0.67 秒の間をおいてから CLEAR! ENTER が出るようにします。

いまは、最後の 1 歩を押し終えたその瞬間に CLEAR! が出ます。 まちがいではないのですが、「解けた！」と感じる前に文字が出てしまい、少しあっけない。 ほんの少しの「間」と、目に見える合図を足します。

step1 で作った「間」と同じしくみです step1 フェーズ 7 で、捕まってから 0.67 秒は GAME OVER を出さず、 Enter も受け付けないようにしました（gameover_frame と GAMEOVER_WAIT）。 今回はそれをクリアの瞬間に使います。
新しく出てくるのは、円を描く pyxel.circb と、文字を右はしにそろえる式くらいです。

1. 考え方

1-1. 画面の上は「左・まんなか・右」の 3 か所

フェーズ 1 で、画面の上に HUD_HEIGHT = 12 ドットの帯を空けておきました （コメントは「手数などを出すために空けておく高さ」）。いよいよ使います。 いまこの帯には、左に STAGE、まんなかに CLEAR! が出ます。 空いている右はしに STEPS を置きます。

左はしの STAGE は x = 2 から書いているので、左に 2 ドット空いています。 右はしもそろえて 2 ドット空けたい。ところが右にそろえるときは、「書き始めの x」を 文字の長さから逆算しなければなりません。

Pyxel の文字は、1 文字が幅 4 ドットの箱に入っています（字が 3 ドット、右にすき間が 1 ドット）。 n 文字なら、箱は 4n ドットです。

  • 箱を右はしにぴったりつけると x = 160 - 4n。いちばん右の 1 ドットは箱のすき間なので、 字の右は 1 ドットしか空きません
  • そこからもう 1 ドット左へずらすと x = 160 - 4n - 1。字の右に 2 ドット空きます
    x = SCREEN_WIDTH - len(text) * 4 - 1

STEPS 21 は 8 文字なので x = 127。 歩数が 3 けたになって STEPS 100（9 文字）になると x = 123—— 右はしは動かず、左へ伸びていきます。

draw_center() の兄弟です draw_center() は (SCREEN_WIDTH - len(text) * 4) // 2 で、左右の空きを半分ずつにしました。 draw_right() は右の空きを 2 ドットに決めて、残りをぜんぶ左に回す。 どちらも、文字の幅 len(text) * 4 から逆算するのは同じです。
こまかい話：「1」の字だけは幅 2 ドットで、箱の左に寄っています。 そのため STEPS 21 のように「1」で終わるときだけ、字の右はしが 1 ドット内側になります （実際に描いて確かめました）。箱の位置はそろっているので、けたがずれることはありません。

1-2. 数えるのは「矢印を押した回数」ではなく「動けた回数」

歩数をどこで数えるかを考えます。 矢印キーを見ている handle_key() で数えると、壁に向かって押したときも数えてしまいます。 壁なら向きが変わるだけで、1 マスも進んでいません。

数えたいのは本当に 1 マス動いたときです。それが決まるのは try_move() のいちばん最後—— 壁や荷物の「関門」をぜんぶ通り抜けて、walk_timer = 1 で歩き出す行のところです。

こんなとき数える？
壁に向かって押した（向きだけ変わる）数えない
押せない荷物に向かって押した数えない
床へ 1 マス歩いた1
荷物を押して 1 マス進んだ1（押しても 1 歩）

矢印を押しっぱなしにしても、歩いている 8 フレームのあいだはキーを見ていない （フェーズ 4）ので、1 マスにつき 1 回しか数えません。

1-3. クリアの「間」は、時刻を覚えて引き算

step1 フェーズ 7 と同じ手順です。

  1. クリアした瞬間の pyxel.frame_count を、self.clear_frame に覚えておく
  2. そのあとは毎フレーム、pyxel.frame_count - self.clear_frame で 「クリアしてから何フレームたったか」を出す
  3. それが CLEAR_WAIT（20）より小さいあいだは、輪を描き、 CLEAR! は出さず、Enter も受け付けない

「見えていないものは押せない」——step1 で決めた約束です。 ENTER の文字が出るのと同じフレームから Enter が効くように、 描くほうと受け付けるほうで同じ CLEAR_WAIT を見ます。

1-4. 輪の大きさを、たった時間から決める

輪の半径は、クリアしてからの経過フレームを 2 で割った数にします。 

            r = self.clear_elapsed() // 2       # 2 フレームに 1 ドットずつ大きく
経過012345…181920
半径 r001122…99（描かない）

経過は毎フレーム 1 ずつ増えるので、半径は 2 フレームに 1 ドットずつ大きくなります。 20 フレームで半径 9——リンゴ 2 個ぶんほどの輪になったところで消えて、CLEAR! に入れかわります。

1 フレームに 1 ドットだと、大きすぎました // 2 をつけずに r = self.clear_elapsed() にすると、最後は半径 19 になります。 荷物が 7 つある 10 面で試すと、輪が盤面いっぱいに重なって、 どれがどのリンゴの輪なのか分からなくなりました。合図は、少し控えめなくらいがちょうどいいようです。

「たった時間から、大きさを計算する」のは、フェーズ 4 で walk_timer から歩いている途中の位置を計算したのと同じ発想です。 ゲームの動きの多くは、この「経過 → 量」の式で作れます。

2. このフェーズで使う機能

機能役割
pyxel.circb(x, y, r, col) 円の線だけを描く。中心が (x, y)、半径 r。 中までぬるのは pyxel.circ（b がない）。rectb と同じく、b は「枠だけ」の印。 このフェーズで初めて出ます
pyxel.frame_count 起動してから何フレーム目か。時刻を覚えておいて、引き算する。step1 フェーズ 7 と同じ使い方
len(text) * 4 文字列の幅（ドット）。draw_center() と同じ
+= self.steps += 1 は self.steps = self.steps + 1 と同じ。step1 のスコアと同じ
A and B は左から調べる A が False なら、B は調べもしない。 このフェーズで初めて、この性質に頼ります（6-4）

「着いた、その瞬間に調べる」の if の中、self.cleared = True のすぐ下に 1 行足します。

3-5. Enter は、待ちが明けてから受け付ける

update_game() の、クリアしたあとの 2 行を書き換えます。

        if self.cleared:                        # クリアした。間をおいてから、Enter で次のステージへ   ← 書き換え
            if self.clear_elapsed() >= CLEAR_WAIT and pyxel.btnp(pyxel.KEY_RETURN):                ← 書き換え

R と Q はこの上で先に調べているので、待ちのあいだでも効きます （フェーズ 8 の 6-4 の並び順のおかげです）。 止めているのは Enter（次の面へ進む）だけです。

3-6. 輪を描く（リンゴより先に）

draw_game() の、壁を描く for のあと、荷物を描く手前に足します。 

                pyxel.blt(self.ox + x * TILE, self.oy + y * TILE,
                            0, u, V_TILE, TILE, TILE)

        # クリアした直後は、リンゴから輪が広がる。リンゴの下から出てくるように、先に描く   ← ここから足す
        if self.cleared and self.clear_elapsed() < CLEAR_WAIT:
            r = self.clear_elapsed() // 2       # 2 フレームに 1 ドットずつ大きく
            for box in self.boxes:
                cx = self.ox + box[0] * TILE + TILE // 2
                cy = self.oy + box[1] * TILE + TILE // 2
                pyxel.circb(cx, cy, r, pyxel.COLOR_YELLOW)
                                                                                    ← ここまで足す
        # 荷物。押している 1 つだけは、主人公といっしょにすべる

cx・cy はリンゴのマスのまんなかです。 マスの左上（self.ox + box[0] * TILE）に、マスの半分 TILE // 2（4）を足しています。

and の左右を入れかえないでください self.clear_elapsed() < CLEAR_WAIT and self.cleared と書くと、 ゲームが始まった瞬間に AttributeError で止まります。理由は 6-4 で。

    def load_stage(self, rows):
        """文字の地図を読んで、壁・主人公・荷物に分ける"""
        self.tiles = []
        self.boxes = []
        self.player_dir = DIR_DOWN      # はじめは下を向いている
        self.walk_timer = 0             # 0 なら止まっている。1～8は歩いている途中
        self.pushing = False            # いまの一歩で荷物を押しているか

        self.steps = 0                  # このステージで歩いた数

        for y in range(len(rows)):
            line = []
            for x in range(len(rows[y])):
                mark = rows[y][x]
                if mark == "@":
                    self.player_x = x
                    self.player_y = y
                    mark = "."          # 主人公の足元は床
                elif mark == "$":
                    self.boxes.append([x, y])
                    mark = "."          # 荷物の下も床
                line.append(mark)
            self.tiles.append(line)

        self.from_x = self.player_x     # 見た目の出発マス
        self.from_y = self.player_y

        # 盤面を画面の中央に置くための、ずらし幅

        board_h = len(self.tiles) * TILE
        self.ox = (SCREEN_WIDTH - board_w) // 2
        self.oy = HUD_HEIGHT + (SCREEN_HEIGHT - HUD_HEIGHT - board_h) // 2

    def update_title(self):
        """タイトル画面。Enter でステージ選択へ"""
        if pyxel.btnp(pyxel.KEY_RETURN):
            self.scene = SCENE_SELECT

    def update_select(self):
        """ステージ選択。矢印でカーソルを動かし、Enter で始める"""
        if pyxel.btnp(pyxel.KEY_LEFT):
            self.move_cursor(-1)
        elif pyxel.btnp(pyxel.KEY_RIGHT):
            self.move_cursor(1)
        elif pyxel.btnp(pyxel.KEY_UP):
            self.move_cursor(-SELECT_COLS)      # 1 段上は、5 つ前
        elif pyxel.btnp(pyxel.KEY_DOWN):
            self.move_cursor(SELECT_COLS)       # 1 段下は、5 つ後

        if pyxel.btnp(pyxel.KEY_RETURN):
            self.start_game()

    def move_cursor(self, step):
        """カーソル（stage_no）を step だけ動かす。選べない面へは動かない"""
        next_no = self.stage_no + step
        if 0 <= next_no < self.opened_count():
            self.stage_no = next_no

    def update_game(self):
        """あそんでいる間の更新"""
        if self.all_cleared:                    # ぜんぶおわった。Enter でタイトルへ
            if pyxel.btnp(pyxel.KEY_RETURN):
                self.stage_no = 0
                self.all_cleared = False
                self.scene = SCENE_TITLE
            return

        if pyxel.btnp(pyxel.KEY_Q):             # ステージ選択へもどる
            self.scene = SCENE_SELECT
            return

        if pyxel.btnp(pyxel.KEY_R):             # いつでも、最初からやり直せる
            self.load_stage(STAGES[self.stage_no])
            return

        if self.cleared:                        # クリアした。間をおいてから、Enter で次のステージへ
            if self.clear_elapsed() >= CLEAR_WAIT and pyxel.btnp(pyxel.KEY_RETURN):
                self.next_stage()
            return
        
        if self.walk_timer > 0:                 # 歩いている途中
            self.walk_timer += 1
            if self.walk_timer > MOVE_FRAMES:   # 隣のマスに着いた
                self.walk_timer = 0
                self.from_x = self.player_x     # 見た目を、いまいるマスに合わせる
                self.from_y = self.player_y
                self.pushing = False
                if self.is_cleared():           # 着いた、その瞬間に調べる
                    self.cleared = True
                    self.clear_frame = pyxel.frame_count    # クリアした時刻を覚えておく
                    # 何面目までクリアしたかを覚える。前の記録より小さくはしない
                    self.cleared_count = max(self.cleared_count, self.stage_no + 1)

        # 止まっていて、まだクリアしていないときだけ、キーを見る    
        if self.walk_timer == 0 and not self.cleared:
            self.handle_key()

    def handle_key(self):
        """矢印キーを見て、押された向きへ 1 歩進もうとする"""
        if pyxel.btn(pyxel.KEY_DOWN):
            self.try_move(DIR_DOWN)
        elif pyxel.btn(pyxel.KEY_UP):
            self.try_move(DIR_UP)
        elif pyxel.btn(pyxel.KEY_LEFT):
            self.try_move(DIR_LEFT)
        elif pyxel.btn(pyxel.KEY_RIGHT):
            self.try_move(DIR_RIGHT)

    def has_box(self, x, y):
        """そのマスに荷物があるかどうかを答える"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                return True
        return False

    def move_box(self, x, y, dx, dy):
        """(x, y) にある荷物を、(dx, dy) だけ動かす"""
        for box in self.boxes:
            if box[0] == x and box[1] == y:
                box[0] += dx
                box[1] += dy
                return

    def on_goal(self, box):
        """その荷物が、ゴールのマスに乗っているか"""
        return self.tiles[box[1]][box[0]] == "O"

    def is_cleared(self):
        """すべての荷物がゴールに乗ったか"""
        return all(self.on_goal(box) for box in self.boxes)

    def clear_elapsed(self):
        """クリアしてから何フレームたったか"""
        return pyxel.frame_count - self.clear_frame

    def next_stage(self):
        """次のステージへ進む。最後だったら全クリア"""
        if self.stage_no + 1 < len(STAGES):
            self.stage_no += 1
            self.load_stage(STAGES[self.stage_no])
        else:
            self.all_cleared = True

    def try_move(self, direction):
        """その向きへ動けるか調べて、動けるときだけ 1 マス進む"""
        self.player_dir = direction     # 動けなくても、向きだけは変える

        dx, dy = MOVES[direction]
        next_x = self.player_x + dx
        next_y = self.player_y + dy

        if self.tiles[next_y][next_x] == "#":   # 行き先が壁なら
            return                              # 何もしないで戻る

        if self.has_box(next_x, next_y):        # 行き先に荷物があるなら
            far_x = next_x + dx                 # 荷物の、1 つ先のマス
            far_y = next_y + dy
            if self.tiles[far_y][far_x] == "#": # その先が壁なら押せない
                return
            if self.has_box(far_x, far_y):      # その先に別の荷物があっても押せない
                return
            self.move_box(next_x, next_y, dx, dy)
            self.pushing = True                 # この一歩は、荷物を押している

        self.player_x = next_x
        self.player_y = next_y
        self.walk_timer = 1                     # ここから 8 フレームかけて歩く
        self.steps += 1                         # 動けたときだけ、1 歩と数える

    def slide_pos(self, origin, from_cell, to_cell):
        """出発マスから到着マスへ、いまどこまで来たかをドットで返す"""
        moved = (to_cell - from_cell) * TILE * self.walk_timer // MOVE_FRAMES
        return origin + from_cell * TILE + moved

    def draw(self):
        """フレーム毎の描画処理。画面を消してから、担当へ渡す"""
        pyxel.cls(pyxel.COLOR_BLACK)    # 各画面で使うので、ここに 1 回だけ

        if self.scene == SCENE_TITLE:
            self.draw_title()
        elif self.scene == SCENE_SELECT:
            self.draw_select()
        else:
            self.draw_game()

        draw_center("SOKOBAN", 30, pyxel.COLOR_YELLOW)

        # ワンコが、リンゴをゴールへ押していく絵

    def draw_select(self):

        draw_center("SELECT STAGE", 16, pyxel.COLOR_YELLOW)

        for no in range(len(STAGES)):
            col = no % SELECT_COLS              # 左から何番目か（0～4）

    def draw_game(self):
        """あそんでいる画面を描く"""

        # 壁を、上の行から 1 マスずつ描く
        for y in range(len(self.tiles)):
            for x in range(len(self.tiles[y])):
                mark = self.tiles[y][x]
                if mark == "#":
                    u = U_WALL
                elif mark == "O":
                    u = U_GOAL
                else:
                    u = U_FLOOR
                pyxel.blt(self.ox + x * TILE, self.oy + y * TILE,
                            0, u, V_TILE, TILE, TILE)

        # クリアした直後は、リンゴから輪が広がる。リンゴの下から出てくるように、先に描く
        if self.cleared and self.clear_elapsed() < CLEAR_WAIT:
            r = self.clear_elapsed() // 2       # 2 フレームに 1 ドットずつ大きく
            for box in self.boxes:
                cx = self.ox + box[0] * TILE + TILE // 2
                cy = self.oy + box[1] * TILE + TILE // 2
                pyxel.circb(cx, cy, r, pyxel.COLOR_YELLOW)

        # 荷物。押している 1 つだけは、主人公といっしょにすべる
        dx, dy = MOVES[self.player_dir]
        push_x = self.player_x + dx             # 押した荷物は主人公の目の前にいる
        push_y = self.player_y + dy
        for box in self.boxes:
            if self.pushing and box[0] == push_x and box[1] == push_y:
                bx = self.slide_pos(self.ox, box[0] - dx, box[0])
                by = self.slide_pos(self.oy, box[1] - dy, box[1])
            else:
                bx = self.ox + box[0] * TILE
                by = self.oy + box[1] * TILE
            u = U_BOX
            if self.on_goal(box):       # ゴールに乗っているあいだは別の絵
                u = U_BOX_ON_GOAL
            pyxel.blt(bx, by, 0, u, V_TILE, TILE, TILE, pyxel.COLOR_BLACK)

        # 主人公
        px = self.slide_pos(self.ox, self.from_x, self.player_x)
        py = self.slide_pos(self.oy, self.from_y, self.player_y)
        v = V_PLAYER_A
        if self.walk_timer >= MOVE_FRAMES // 2:     # 歩きの後半は、足を入れ替える
            v = V_PLAYER_B
        pyxel.blt(px, py, 0, self.player_dir * TILE, v, TILE, TILE, pyxel.COLOR_GRAY)

        # 画面の上の表示
        if self.all_cleared:
            draw_center("ALL CLEAR!  ENTER=TITLE", 3, pyxel.COLOR_YELLOW)
        else:
            pyxel.text(2, 3, f"STAGE {self.stage_no + 1}/{len(STAGES)}",
                       pyxel.COLOR_GRAY)
            draw_right(f"STEPS {self.steps}", 3, pyxel.COLOR_GRAY)
            if self.cleared and self.clear_elapsed() >= CLEAR_WAIT:
                draw_center("CLEAR!  ENTER", 3, pyxel.COLOR_YELLOW)

6. コードの解説

6-1. 数える行は「関門をぜんぶ通ったあと」

self.steps += 1 をほかの場所に書くとどうなるか、実際に動かして比べました。

書いた場所壁へ 1 秒押しつづける床を 2 歩荷物を 1 回押す
try_move() のいちばん最後（今回）021
try_move() のいちばん上3021
荷物の if の中（インデントが深い）001

いちばん上に書くと、壁に押しつけているだけで 1 秒に 30 ずつ増えます。 止まっているあいだ、handle_key() は毎フレーム try_move() を呼ぶ （btn は押しているあいだずっと True）ので、 関門ではね返されるたびに数えてしまうからです。

「起きたことを数える行は、それが本当に起きたと決まった場所に書く」—— フェーズ 8 の 6-2 で、クリア記録を「クリアした瞬間」に書いたのと同じ考え方です。

6-2. 0 に戻すのは load_stage()——cleared_count とのちがい

変数R でやり直したら次の面へ進んだら置き場所
cleared_count（フェーズ 8）戻ってほしくない戻ってほしくない__init__()
steps（今回）0 に戻ってほしい0 に戻ってほしいload_stage()

load_stage() は、面を始めるとき（start_game()）、R でやり直すとき、 次の面へ進むとき（next_stage()）の 3 つの道すべてで呼ばれます。 ここに置けば、どの道から入っても 0 からです。

ためしに __init__() に置いて動かすと、2 歩あるいて R を押しても STEPS 2 のまま。 そこから 5 歩で解いて 2 面へ進むと、2 面は 7 から始まりました。 どこにも書かないと、面が始まった瞬間に AttributeError: 'App' object has no attribute 'steps' で止まります。

6-3. 同じ引き算が 3 か所に出たら、関数にする

pyxel.frame_count - self.clear_frame は、次の 3 か所で使います。

場所見ていること
update_game()待ちが明けたか（Enter を受け付けるか）
draw_game() の輪待ちのあいだか、と、輪の半径
draw_game() の画面の上待ちが明けたか（CLEAR! を出すか）

step1 フェーズ 7 では「同じ数字が 2 か所に出たら、定数へ格上げ」としました。 同じ式が何か所にも出てきたら、関数へ格上げします。 フェーズ 8 の opened_count() と同じ、計算した値を答えるだけの小さな関数です。

名前がつくと、if self.clear_elapsed() >= CLEAR_WAIT が 「クリアしてからの経過が、待ち時間以上なら」と、そのまま読めるようになります。

() を忘れると TypeError self.clear_elapsed < CLEAR_WAIT と () を忘れると、クリアした瞬間に TypeError: '<' not supported between instances of 'method' and 'int' で止まります。 フェーズ 8 の opened_count と同じで、「関数を呼んだ答え」ではなく「関数そのもの」と比べています。
逆に pyxel.frame_count は関数ではなくただの数なので、pyxel.frame_count() と書くと TypeError: 'int' object is not callable（「数は呼び出せません」）になります。

6-4. and は左から調べて、答えが決まったらやめる

A and B は「A も B も True なら True」でした。 ということは、A が False の時点で、B がなんであっても答えは False です。 そこで Python は、A が False なら B を調べもしません（関数なら、呼び出しもしない）。

これが、輪の if で効いています。self.clear_frame はクリアした瞬間に初めて作られる変数です。 クリアする前に clear_elapsed() を呼ぶと、まだ無い self.clear_frame を引き算しようとして止まります。

左右を逆にすると、ゲーム画面になった最初のフレームで止まります（実際に確かめました）。 and の左に「右を調べても大丈夫か」を置く——これは、この先もよく使う書き方です。

なぜ clear_frame を、最初に 0 で作っておかないのか load_stage() で self.clear_frame = 0 としておけば、順番を逆にしてもエラーは出ません。 でもそうすると、self.clear_frame = pyxel.frame_count の行を書き忘れても、エラーにならないのです。 経過が「起動してからのフレーム数」になってしまい、輪は出ず、CLEAR! がすぐ出る—— ただ演出が消えるだけの、だまって壊れる動きになります。
step1 の gameover_frame と同じく、書き忘れたらすぐ止まって気づけるほうを選んでいます。

6-5. 描いた順が、重なる順

step1 フェーズ 3 で「描く順番＝重なる順番」と学びました。あとから描いたものほど手前に来ます。 輪をリンゴより先に描いたのは、輪がリンゴの下から出てくるようにするためです。

いま draw_game() は、床と壁 → 輪 → リンゴ → ワンコ → 画面の上の文字の順に描いています。 ワンコも輪のあとなので、輪はワンコのうしろを通ります。

8. 次のフェーズ

次は効果音と BGMです。step1 フェーズ 9 の復習で、リソースエディタで音を作り、 play と playm で鳴らします。

鳴らす場所は、もうできています。歩いた（self.steps += 1 の隣）、 押した（self.pushing = True の隣）、クリアした（self.clear_frame = … の隣）。 step1 で決めた「効果音は、変化させている行の隣で鳴らす」がそのまま使えます。 今回つくった 0.67 秒の間は、クリアの短いジングルを鳴らすのにちょうどいい長さです。
