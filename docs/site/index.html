learning_pyxel

Python のゲームライブラリ Pyxel で、ゲーム制作プログラミングを一から学ぶ記録

このサイトについて

Pyxel を使ったゲーム制作を、完成版をいきなり写すのではなく、いくつかのフェーズに 分けて段階的に組み立てていく学習サイトです。各フェーズは 「考え方 → 必要な API → コード → 解説」 の 4 点セットで構成されています。 コードは自分の手で入力し、実行して確かめながら進めます。

学習ステップ

step0

準備：星空を飛ぶ宇宙船

環境構築と、Pyxel の機能を広く浅く体験するアニメーション作品。文字表示・図形描画・スプライト・キー入力・BGM・GitHub 公開までを一通り行う。作品の閲覧もWeb上で可能です。
step1

お菓子集めゲーム

お化けに捕まらずにどれだけお菓子を集められるかを競うゲーム。タイトル／ゲーム／ゲームオーバーの画面遷移を実装する。

step2

倉庫番

荷物を押して所定の位置に運ぶパズル。10 ステージ制とタイトル画面を備える。

step3

縦スクロールシューティング

3 ステージ制。中ボス・ボス、弾幕、パワーアップアイテムが登場する。

step4

未定

step3 まで完了してからジャンルと内容を検討する。

memo

備忘録

Python や Pyxel について出た疑問と、その答えを蓄積していくページ。

 資料

BGM の作り方

音楽の知識ゼロから、Pyxel でそれらしい曲を組み立てる手順。コード進行・音階・リズム・音色の選び方をまとめた読み物。
作品を公開しています Pyxel の Web 配布機能（pyxel package → pyxel app2html）で HTML 1 枚に まとめてあるので、インストールなしでブラウザからそのまま動かせます。
▶ Star Voyager をブラウザでみる — 星空を飛ぶ宇宙船のアニメーション（step0 の作品）
▶ dot_fish をブラウザでみる — 魚が泳ぐデジタル時計。毎正時にチャイムが鳴る（step0 の復習作品）
▶ Hiyoko Anime をブラウザでみる — 花を降らせてヒヨコを育てるアニメーション。BGM つき（step0 の復習作品）

開発環境

項目内容
OSWindows 11
Python3.12.10
Pyxel2.9.9
エディタVisual Studio Code

インストール

pip install pyxel

正しく入ったかは、付属のサンプルを動かして確かめられます。

pyxel copy_examples
cd pyxel_examples
pyxel run 01_hello_pyxel.py
ウィンドウの閉じ方 Pyxel のウィンドウは Esc キーで終了します。ウィンドウ右上の × でも閉じられます。
